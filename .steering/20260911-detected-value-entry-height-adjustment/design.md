# Design: 検出値ラベル修正 + 表示欄縦幅微調整

## 対象
- `src/PressureReader.py`

## 設計方針
- ラベル文言を仕様通りに修正する。
- 検出値3項目のEntryに限定して表示高さをわずかに下げる。
- ラベル側のスタイル/配置は変更しない。
- 共通フォント `custom_font` には影響させず、検出値専用フォント変数を利用する。

## 変更内容
- セクションラベルを `選択範囲の検出値：` へ変更。
- 項目ラベルから末尾コロンを除去。
- `ttk.Entry` はWindowsテーマ依存で高さが変わりにくいため、検出値3項目のみ `tk.Entry` へ切替。
- `detected_value_font = ("Meiryo ui", 13, "bold")` を適用し、視認上の縦幅を下げる。
- 以下3つのEntryに同一設定を適用。
  - `atai_ave_entry`
  - `atai_max_entry`
  - `atai_min_entry`

## 影響評価
- ロジック変更なし（見た目のみ）。
- Entry参照名や値更新関数は変更しないため、既存処理への影響は最小。
