# Requirements: 検出値ラベル修正 + 表示欄縦幅微調整

## 目的
- `検出値（平均）` / `検出値（最大）` / `検出値（最小）` の値表示欄が縦方向にくっついて見える問題を改善する。

## 要件
- セクションラベルを `選択範囲の検出値：` に変更する。
- 項目ラベルを `検出値（平均）` / `検出値（最大）` / `検出値（最小）` に変更する（末尾のコロンなし）。
- 検出値3項目の値表示欄（Entry）の縦幅を、現状より少しだけ小さくする。
- ラベル位置・ラベル文字サイズは変更しない。
- 検出値の計算/表示ロジックは変更しない。
- 既存のクリア動作（選択範囲クリア、画面リセット、画像読み込み時クリア）に回帰を出さない。
