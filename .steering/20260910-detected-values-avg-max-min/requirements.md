# Requirements: 検出値表示（平均/最大/最小）拡張

## 目的
- 右パネルの検出値表示を、単一値から「平均 / 最大 / 最小」の3値表示へ拡張する。

## 機能要件
- 検出値エリアに以下を表示する。
  - `検出値（平均）`
  - `検出値（最大）`
  - `検出値（最小）`
- 単位 `MPa` を各行に表示する。
- 選択範囲の再計算時に3値を同時更新する。
- 平均値は従来の検出値表示と同一の意味・フォーマットにする。

## 非機能要件
- 既存の選択範囲処理（四角形 / 多角形 / 円）と互換性を維持する。
- 既存の「測定範囲外」表示ルールを維持する。
- 文字コードは UTF-8 を維持し、文字化けを発生させない。
