# Requirements: 標準色見本・スケーリングの色トグル化

## 目的
- 標準色見本処理ボタンとスケーリングボタンのON状態を、テキストではなく色で判別できるようにする。

## 要件
1. 標準色見本処理ボタンはテキストを固定（`標準色見本処理`）にし、`ON/OFF`文字を表示しない。
2. 標準色見本処理ボタンのON中は `RGB(155,253,155)`（`#9BFD9B`）で表示する。
3. スケーリングボタンをトグル化し、ON中は `RGB(155,253,155)`（`#9BFD9B`）で表示する。
4. スケーリングの完了・キャンセル・モード切替時はOFFへ戻し、通常色へ復帰する。
5. 既存の読取・解析・出力処理に回帰を出さない。
