# Design: 多角形ハンドルとテキスト非接触の再対策

## 実装方針
- `show_polygon_point_pressure_text(...)` 内で多角形頂点ラベル専用の位置決定を行う。
- 既存候補（上/右/左/下）をベースに、右方向シフト（4px刻み、最大40px）を追加して評価する。

## 判定ルール
- 回避対象:
  - 既存 `_collect_avoid_bboxes(...)`
  - 全頂点ハンドルBBox（10px拡張）
- 合格条件:
  - 重なり面積 `overlap == 0`
  - 全頂点ハンドルとの最短距離 `>= 4px`
- スコア:
  - 合格優先 → 重なり面積小 → 最短距離大 → シフト量小 → クランプ量小

## 影響範囲
- 多角形モードの各頂点点圧ラベル表示のみ。
- 既存の計算処理、タグ運用、他モード処理には影響しない。
