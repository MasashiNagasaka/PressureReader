# Requirements: スプラッシュ2 見栄え改善

## 目的
- スプラッシュ2案内画面の見栄えと可読性を向上する。

## 要件
- ヘッダー + 本文の2段構成にする。
- ヘッダーに `ご案内` を表示する。
- 本文は既存の3箇条を維持する。
- 配色を整理する。
  - 全体背景: `#f4f7fb`
  - ヘッダー背景: `#1f3a5f`
  - ヘッダー文字: `#ffffff`
  - 本文文字: `#1f2d3d`
  - 箇条書き記号: `#0f6ab4`
- フォントは以下を使用する。
  - タイトル: `("Meiryo ui", 16, "bold")`
  - 本文: `("Meiryo ui", 13)`
- 表示時間8秒は維持する。
