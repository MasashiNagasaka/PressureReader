# Design: 検出値表示欄の縦間隔調整（温度/湿度欄準拠）

## 対象
- `src/PressureReader.py`

## 設計方針
- 変更は `detected_value_frame` 内の `grid` 縦余白（`pady`）に限定する。
- 温度/湿度欄と同様に、先頭行にやや大きめの上余白を持たせ、2行目以降に最小限の上余白を付ける。
- ロジックや文言は変更しない。

## 変更内容
- `検出値（平均）` 行: `pady=(8,0)` に調整。
- `検出値（最大）` 行: `pady=(2,0)` に調整。
- `検出値（最小）` 行: `pady=(2,0)` に調整。
- 対象は各行のラベル、Entry、`MPa` ラベル。

## 影響評価
- 見た目のみ変更。
- Entry参照名、値更新、クリア処理には影響なし。
