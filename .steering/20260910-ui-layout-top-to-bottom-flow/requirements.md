# Requirements: ui-layout-top-to-bottom-flow

## 目的
- 右側UIパネルの操作順を上から下へ統一する。

## 要件
1. 画面上部に画像準備（`PDF→PNG変換`、`PNGを開く`）を配置する。
2. `PDF→PNG変換` の直上に `画像準備：` ラベルを配置する（既存の `解析条件：` / `検出値：` と同フォーマット）。
3. `解析条件：` ラベルは `感圧紙種類セレクト` の直上に配置する。
4. 解析条件設定は以下順で配置する。
   - 感圧紙種類セレクト
   - 標準色見本処理
   - 明度設定欄
   - 温度 / 湿度
   - スケーリング
   - PNGに解析条件を保存
   - 解析条件をコピー
5. 範囲選択（形状選択、選択範囲クリア）を表示調整より先に配置する。
6. 表示調整（測定範囲可視化、検出値、圧力最大点）を範囲選択の後に配置する。
7. `選択範囲Excel出力` の直上に `出力：` ラベルを配置する（既存ラベルと同フォーマット）。
8. 出力（選択範囲Excel出力）を下部に配置する。
9. `画面リセット` の直上に `入力内容クリア：` ラベルを配置する（既存ラベルと同フォーマット）。
10. 画面リセットは最下部に配置する。

## 非機能要件
- 配置変更のみを行い、既存の各機能ロジックは変更しない。
- ボタン幅同期（解析条件をコピーと画面リセット）は維持する。
