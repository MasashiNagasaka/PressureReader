# Design: ui-layout-top-to-bottom-flow

## 変更対象
- `src/PressureReader.py`

## 設計方針
- `ttk` ウィジェットの `grid(row=...)` 再配置のみ実施する。
- イベントハンドラ、計算処理、ファイルI/O処理には手を入れない。
- 明度設定欄は `update_entries_and_buttons()` の開始行オフセットのみ変更し、動的表示数の仕様は維持する。

## 実装ポイント
1. 明度欄の動的配置を `row=2+i` から `row=7+i` に変更。
2. 解析条件系（温湿度・スケーリング・標準色見本処理）の行番号を新フローに合わせて再配置。
3. `button_metacopy`（PNGに解析条件を保存）を `button_jouken`（解析条件をコピー）の直上へ移動。
4. 範囲選択ブロック（形状ラジオ、クリア）を表示調整ブロックより上へ移動。
5. 画像準備ボタン（PDF→PNG、PNGを開く）を最上部へ移動。
6. `PDF→PNG変換` 直上に `画像準備：` ラベル（`Custom.TLabel`）を追加。
7. 出力ボタンと画面リセットを最下部に再配置。

## 互換性・回帰防止
- `sync_reset_button_width_to_metacopy()` はそのまま維持し、幅合わせ仕様を保つ。
- 既存のウィジェット変数名、コマンド参照、バインドは変更しない。
