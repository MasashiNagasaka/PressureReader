# Requirements: 円形モードのサイズ入力ダイアログと単位自動切替

## 目的
- 円形モードで中心クリック後にサイズを数値入力して確定できるようにする。
- スケーリング設定有無で入力単位を `mm` / `px` 自動切替する。
- 円確定前の点圧表示を抑止し、確定後クリックで点圧表示する。

## 要件
- 中心クリック時にサイズ入力ダイアログを表示する。
- 単位表示はスケーリング設定済みなら `mm`、未設定なら `px`。
- 円サイズ表示は入力単位に合わせて `mm` / `px` で表示する。
- 入力完了前は点圧表示しない。
- 円確定後のクリック/ドラッグ優先ルール、再計算、既存編集操作は維持する。
