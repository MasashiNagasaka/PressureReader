# Requirements: 起動時スプラッシュ2（info案内ウィンドウ）追加

## 目的
- 起動時に事前準備物を明確に案内する。

## 要件
- 起動順序を `スプラッシュ1 -> スプラッシュ2 -> メイン` にする。
- スプラッシュ2は8秒表示後に自動クローズする。
- 以下文言を表示する。
  - 本アプリ使用時は、事前に下記を準備して下さい。
  - ・感圧紙(圧力計測後)および標準色見本の画像PDF
  - ・圧力計測時の温度[℃]、湿度[%]
  - ・感圧紙のスケール(寸法)[mm]
- フォントは `("Meiryo ui", 14)`（boldなし）にする。
