# PNGを開く後の成功メッセージ表示 仕様書

> 作成日: 2026-09-16
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景

`PNGを開く` ボタンで画像読込後、処理成功が画面上で明示されないため、  
ユーザーが「開けたかどうか」を即時に判断しにくい。

---

## 2. 目的

- PNG読込成功時に、ユーザーへ完了メッセージを表示する。

---

## 3. 要件

1. `PNGを開く` 操作で画像読込が成功した場合、`ファイルを開きました` を表示する。
2. キャンセル時は表示しない。
3. 読込失敗時は既存のエラーメッセージを維持する。
4. 既存フロー（画像表示、選択範囲クリア、状態初期化）に影響を出さない。

---

## 4. 仕様詳細

- 表示タイミング:
  - 画像が正常に読み込まれ、キャンバス表示まで完了した直後。
- 表示方法:
  - 既存の短時間ガイダンス表示と同系統（`Label` + `after` 自動消去）を優先。
  - 文言: `ファイルを開きました`
  - 色は既存メッセージと統一する（`fg="white"`, `bg="#c942a5"`）。
- 表示時間:
  - 1.5〜2.0秒程度（既存ガイダンスと同等）。

---

## 5. 受け入れ条件

- [ ] PNG読込成功時に `ファイルを開きました` が表示される。
- [ ] ファイル選択キャンセル時は表示されない。
- [ ] 既存の失敗メッセージ・既存処理に回帰がない。
