# exe一時フォルダ掃除方針 仕様書

> 作成日: 2026-09-16
> ステータス: Draft
> 想定コマンド: `/add-feature`

---

## 1. 方針（採用）

- 起動中は現在の `_MEI...` を触らない
- 終了後に掃除する
- 起動時に「現在実行中以外の古い `_MEI...` のみ」を対象に掃除する

---

## 2. 背景

PyInstaller onefile の exe 実行時は、実行ファイルの中身が `_pressure_tmp\_MEIxxxxxx` に展開される。  
この `_MEIxxxxxx` には実行中に必要な `config/sheet_setting.csv` や `cv2.pyd` などが含まれるため、
実行中の `_MEI...` を削除対象にすると、CSV未検出やアクセス拒否エラーの原因になる。

---

## 3. 仕様詳細

### 3.1 起動時掃除

- 対象ディレクトリ: `_pressure_tmp` 直下
- 掃除対象: 「現在実行中の `_MEI...` 以外」の `_MEI...` ディレクトリのみ
- 非対象:
  - 現在実行中の `_MEI...`
  - `_MEI...` 以外の未知ディレクトリ

### 3.2 終了時掃除

- `WM_DELETE_WINDOW` から終了処理を呼ぶ
- 終了後の別プロセスで `_pressure_tmp` を掃除する
- ファイルロックを考慮し、短時間リトライを許容する

### 3.3 python 実行との整合

- `python PressureReader.py` 実行時は onefile 展開がないため、従来の挙動を維持する
- exe 実行時のみ上記の `_MEI...` 保護ロジックを適用する

---

## 4. 受け入れ条件

- [ ] exe 起動時に `sheet setting csv not found` が発生しない
- [ ] exe 起動時に `_MEI...` のアクセス拒否による異常終了が発生しない
- [ ] 起動時に古い `_MEI...` が掃除される（現在実行中は残る）
- [ ] 終了後に `_pressure_tmp` が最終的に掃除される

---

## 5. 実装時注意

- 文字化け防止のため、仕様書・コードとも UTF-8 で保存する
- 削除処理は必ずパス検証（`_pressure_tmp` 配下限定）を行う
