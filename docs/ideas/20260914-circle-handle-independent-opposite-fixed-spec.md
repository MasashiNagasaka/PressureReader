# 円形モードのハンドル独立移動（反対側固定）仕様書

> 作成日: 2026-09-14
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- 現在の円形モードでは、上下または左右のハンドルをドラッグすると、中心対称の計算により反対側ハンドルも連動して動く。
- ユーザー要望として、ドラッグしたハンドルのみを動かし、反対側ハンドルは固定したい。
- 意図した方向だけ微調整できるようにして、選択範囲調整の操作性を高める。

---

## 2. スコープ

### 今回含めるもの
- 円形モード確定後のハンドルドラッグで、ドラッグした片側ハンドルのみ移動する。
- 反対側ハンドルはドラッグ中に固定される。
- 既存の円内部ドラッグ移動（形状全体移動）は維持する。

### 今回含めないもの（将来対応）
- 四角形/多角形モードの変更
- 点圧表示仕様の変更
- 右クリック時の「真円化（半径統一）」仕様の変更

---

## 3. ユーザーストーリー

- 解析担当者として、円形選択の左（または右・上・下）だけを詰めたいとき、反対側を動かさずに調整したい。

---

## 4. 機能要件

### 4.1 左右ハンドル
- [ ] 左ハンドルをドラッグした場合、左辺のみ移動し、右辺は固定する。
- [ ] 右ハンドルをドラッグした場合、右辺のみ移動し、左辺は固定する。

### 4.2 上下ハンドル
- [ ] 上ハンドルをドラッグした場合、上辺のみ移動し、下辺は固定する。
- [ ] 下ハンドルをドラッグした場合、下辺のみ移動し、上辺は固定する。

### 4.3 幾何拘束
- [ ] ドラッグ後の中心座標と半径は、固定辺と移動辺から再計算する。
- [ ] 幅・高さが 0 以下にならないよう最小サイズを設ける（例: 幅/高さ 2px 以上）。
- [ ] 反対側を追い越す操作が発生した場合は、最小サイズでクランプし、ハンドルの役割を入れ替えない。

### 4.4 既存挙動維持
- [ ] 円内部ドラッグでの全体移動は従来どおり可能。
- [ ] ハンドルドラッグ後の範囲再計算（平均/最大/最小、高圧検出マーク）は従来どおり実行。
- [ ] 確定後クリック時の点圧表示優先ルール（ドラッグ発生時は編集優先）は維持する。

---

## 5. 非機能要件

- パフォーマンス: ハンドルドラッグ中の描画更新で体感遅延がないこと。
- 信頼性: 連続ドラッグ・極小サイズ付近で例外を出さないこと。
- 一貫性: 既存のクリック/ドラッグ判定ロジックと矛盾しないこと。

---

## 6. 技術的考慮事項（参考）

> このセクションは壁打ち時点のメモです。詳細設計は `/add-feature` 実行時に `steering/design.md` として生成されます。

### 現状の原因
- `on_mouse_drag` のハンドル分岐で `radius_x = abs(event.x - center_x)` / `radius_y = abs(event.y - center_y)` を使っているため、常に中心対称となり反対側が連動する。

### 実装アプローチ（案）
- ハンドルドラッグ時は `canvas.coords(circle_id)` から現行の `(x0, y0, x1, y1)` を取得する。
- ドラッグ対象に応じて移動辺のみ更新し、反対辺を固定したままクランプする。
  - 左: `x0` のみ更新、`x1` 固定
  - 右: `x1` のみ更新、`x0` 固定
  - 上: `y0` のみ更新、`y1` 固定
  - 下: `y1` のみ更新、`y0` 固定
- 更新後の `x0,x1,y0,y1` から `center_x, center_y, radius_x, radius_y` を再計算し、`update_circle()` に反映する。

### 既存コードへの影響（想定）
- 変更: `src/PressureReader.py`
  - `on_mouse_drag`（`dragging_handle` 分岐）
  - 必要に応じて円形更新補助関数（新規追加の可能性）
- 参照: `update_circle`, `on_mouse_up`, `calculate_brightness3`

### 注意点・リスク
- 最小サイズクランプ不足だと 0 除算や表示崩れにつながる可能性がある。
- 右クリックの真円化処理は既存仕様のままなので、ハンドルで楕円調整後に右クリックすると真円へ寄る現仕様を維持する。

---

## 7. 受け入れ条件

- [ ] 左ハンドルドラッグで左側のみ移動し、右側は固定される。
- [ ] 右ハンドルドラッグで右側のみ移動し、左側は固定される。
- [ ] 上ハンドルドラッグで上側のみ移動し、下側は固定される。
- [ ] 下ハンドルドラッグで下側のみ移動し、上側は固定される。
- [ ] 反対側を越える操作時に最小サイズで止まり、挙動が破綻しない。
- [ ] 円内部ドラッグ移動、点圧表示、範囲再計算に回帰がない。
- [ ] 文字化けが発生していない。
