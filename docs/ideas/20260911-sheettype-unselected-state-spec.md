# 感圧紙種類リストの未選択状態導入 仕様書

> 作成日: 2026-09-11
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- 解析条件の先頭操作として「感圧紙種類の選択」を明確化したい。
- 初期状態で他項目が見えていると、未選択のまま先に進みやすく操作ミスにつながる。
- 未選択状態を導入し、選択完了まで必要最小限のUIのみ表示する。

---

## 2. スコープ

### 今回含めるもの
- 感圧紙種類リストボックスの未選択状態（プレースホルダ状態）導入
- 未選択時の解析条件セクション表示制御
- 未選択時の `選択範囲Excel出力` 押下ガード
- 初期状態およびPDF変換後の未選択復帰
- PNG読込時のメタデータ有無に応じた未選択判定

### 今回含めないもの
- 感圧紙種類リストの既存有効項目（各紙種）の名称変更
- 圧力計算ロジックそのもの
- スプラッシュ仕様の変更

---

## 3. 仕様

### 3.1 未選択状態の定義
- 未選択状態のデフォルト表示文言は `感圧紙を選択` とする。
- リスト項目に `感圧紙を選択` を追加し、リストの最下部に配置する。
- 内部的には `感圧紙を選択` が選ばれている状態を「未選択状態」とみなす。

### 3.2 未選択状態へ遷移するタイミング
- 画面初期状態で未選択状態にする。
- `PDF⇒PNG変換` ボタン押下後に自動表示された画像で未選択状態にする。
- `PNGを開く` 実行時:
  - メタデータに感圧紙種類があれば、その種類を選択状態にする。
  - メタデータに感圧紙種類がなければ、未選択状態にする。

### 3.3 解析条件セクションの表示制御
- 未選択状態（`感圧紙を選択` 選択中）のとき、解析条件セクションでは「感圧紙種類リストボックス」以外を表示しない。
- 非表示対象:
  - `標準色見本処理` ボタン
  - 明度関連の状態表示/入力欄（見本行）
  - `温度[℃]` 入力欄
  - `湿度[%]` 入力欄
  - `ｽｹｰﾘﾝｸﾞ` ボタン + 値表示 + 単位表示
  - `PNGに解析条件保存`
  - `解析条件をコピー`
- 感圧紙種類が有効項目に切り替わったら、上記を再表示する。

### 3.4 Excel出力ガード（未選択時）
- `選択範囲Excel出力` ボタンは有効状態のまま維持する。
- ただし未選択状態で押下された場合、出力処理に進まずオーバレイメッセージを表示する。
- 表示文言:
  - `感圧紙の種類をリストから選択してください`
- 表示方式:
  - 既存中央オーバーレイ方式（既存ガードと同じ系統）

---

## 4. 技術的考慮事項（参考）

- リスト選択の値変更時処理（既存 `selected_var` 連動）で未選択判定を行う。
- 表示/非表示は既存の `grid` 制御に合わせて `grid` / `grid_forget` で切替する。
- PNGメタ復元時は「メタに種類あり/なし」で遷移先を分岐する。
- Excel出力の既存ガード（選択範囲・スケーリング等）より先に、未選択ガードを評価する。

---

## 5. 受け入れ条件

- [ ] 起動直後、感圧紙種類リスト表示が `感圧紙を選択` になる
- [ ] リスト最下部に `感圧紙を選択` が存在する
- [ ] 未選択状態では解析条件セクションでリストボックス以外が非表示になる
- [ ] 有効な感圧紙種類を選ぶと、非表示項目が再表示される
- [ ] `PDF⇒PNG変換` 後の自動表示画像で未選択状態になる
- [ ] `PNGを開く` でメタデータに感圧紙種類がなければ未選択状態になる
- [ ] `PNGを開く` でメタデータに感圧紙種類があれば該当種類が選択される
- [ ] 未選択状態で `選択範囲Excel出力` 押下時、`感圧紙の種類をリストから選択してください` が表示される
- [ ] 未選択状態で `選択範囲Excel出力` は実行されない
- [ ] 文字化けが発生していない
