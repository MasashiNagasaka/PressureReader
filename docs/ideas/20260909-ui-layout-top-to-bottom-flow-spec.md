# UI配置見直し（上から下の操作フロー）仕様メモ

> 作成日: 2026-09-09
> ステータス: Draft
> 用途: `/add-feature` 実装前の配置方針整理

---

## 1. 背景と目的
- 現在の右側パネルは、操作順に対してボタン配置が前後しており、初見ユーザーが迷いやすい。
- 目的は「上から下に読むだけで操作できる」並びに統一すること。

---

## 2. 現状課題（操作フロー観点）
- 画像準備系ボタン（`PDF→PNG変換` / `PNGを開く`）が下部にあり、最初に押すべき操作が見つけづらい。
- 解析条件エリアと、範囲選択・表示調整・出力エリアの境界が弱い。
- `画面リセット` は最下部で良いが、操作終了系として意図が伝わる配置にする。

---

## 3. 提案レイアウト（上→下）
### 3.1 Step 1: 画像準備
- `画像準備：` ラベル（既存の `解析条件：` / `検出値：` と同フォーマット）
- `PDF→PNG変換`
- `PNGを開く`

### 3.2 Step 2: 解析条件設定
- 感圧紙種類セレクト
- `標準色見本処理`
- 明度設定欄（見本ボタン＋Entry群）
- 温度 / 湿度
- スケーリング
- `PNGに解析条件を保存`
- `解析条件をコピー`

### 3.3 Step 3: 範囲選択
- 範囲選択形状（四角形 / 多角形 / 円）
- `選択範囲クリア`

### 3.4 Step 4: 表示調整・確認
- `測定範囲可視化 ON/OFF`
- 検出値（MPa）
- 圧力最大点スライダ

### 3.5 Step 5: 出力
- `選択範囲Excel出力`

### 3.6 Step 6: 画面復帰
- `画面リセット`（最下部固定）

---

## 4. 配置ルール
- 各Stepの先頭にラベルを置く（例: `Step1 画像準備`）。
- 同じStep内のボタン幅・左余白・縦間隔は統一。
- 既存アイコン・既存文言は原則維持（並び替え優先）。
- スクロール前提UIのため、上位Stepほど上に固定して視認性を上げる。

---

## 5. 実装方針（最小変更）
- `grid(row=...)` の再配置を中心に対応（ロジック変更は最小）。
- 既存コールバック関数は変更しない。
- 既存のボタンサイズ調整ロジック（`解析条件をコピー` と `画面リセット` の幅合わせ）は維持。

---

## 6. 受け入れ基準
- ユーザーが「上から順に」操作したとき、画像準備→条件設定→範囲選択→表示調整→出力まで自然に完了できる。
- 主要ボタン文言・機能は変更されない（配置のみ変更）。
- `PNGに解析条件を保存` ボタンが操作フロー上に明示され、`解析条件をコピー` の直上に配置される。
- `画像準備：` ラベルが `PDF→PNG変換` ボタンの直上にあり、`解析条件：` / `検出値：` と同一フォーマットで表示される。
- `画面リセット` が最下部に残る。
- 既存の機能回帰（PDF変換、PNG読込、標準色見本処理、Excel出力）がない。

---
