# 標準色見本・スケーリング ボタンのトグル化と色状態表示 仕様書

> 作成日: 2026-09-16
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- `標準色見本処理` ボタンはトグル化されたが、テキスト `：ON / ：OFF` 表示は不要。
- ON中を直感的に判別できるよう、ボタン色で状態を示したい。
- `スケーリング` ボタンも同じ思想でトグル化し、状態判別を統一したい。

## 2. スコープ

### 今回含めるもの
- `標準色見本処理` ボタン:
  - テキスト末尾の `：ON / ：OFF` を廃止
  - ON時はボタン色を変更して状態表示
- `スケーリング` ボタン:
  - ON/OFFトグル化
  - ON時はボタン色を変更して状態表示
  - OFF時は通常色へ戻す
- 両ボタンで「ON状態の意味」を明確に定義する

### 今回含めないもの（将来対応）
- 右ペイン全ボタンの共通デザイン刷新
- アイコンファイル自体の新規制作（既存アセットで対応できる範囲を優先）

## 3. ユーザーストーリー

- ユーザーとして、色見本モードが有効かどうかをボタン色で即座に判断したい。
- ユーザーとして、スケーリングの点選択待ち状態かどうかをボタン色で判断したい。
- ユーザーとして、状態表示方法（ON時の見せ方）が2つのボタンで統一されていてほしい。

## 4. 機能要件

### 4.1 標準色見本処理ボタン
- [ ] ボタンテキストは常に `標準色見本処理`（`：ON / ：OFF` を付けない）
- [ ] OFF → 押下で ON（`set_mode_rect("14")`）
- [ ] ON → 押下で OFF（`set_mode_rect("99")`）
- [ ] ON中はボタン色をON色へ変更
- [ ] 色見本矩形確定後は自動でOFFに戻し、通常色へ戻す

### 4.2 スケーリングボタン
- [ ] スケーリングボタンにトグル状態（ON/OFF）を追加
- [ ] OFF → 押下で ON（線の2点選択待ちモード開始）
- [ ] ON → 再押下で OFF（線選択キャンセル、イベント復帰）
- [ ] ON中はボタン色をON色へ変更
- [ ] 換算係数設定が完了したときは自動でOFFへ戻し、通常色へ戻す
- [ ] ダイアログキャンセル時もOFFへ戻し、通常色へ戻す

### 4.3 ON状態の定義
- [ ] 標準色見本ボタン ON: 「色見本矩形をこれから選択する状態」
- [ ] スケーリングボタン ON: 「基準線（2点）をこれから選択する状態」

### 4.4 見た目仕様
- [ ] ON判別はテキストではなく色で行う
- [ ] 通常色/ON色は2ボタンで統一方針にする
- [ ] ホバー表示はON/OFF状態を壊さない（ON中にホバーしてもON色優先）
- [ ] ON中のボタン色は暫定で `RGB(155,253,155)`（HEX: `#9BFD9B`）を適用する

## 5. 非機能要件

- 可読性: ON/OFF状態が1秒以内に視認可能であること
- 一貫性: 標準色見本とスケーリングで同じ状態表現ルールを使うこと
- 互換性: 既存の明度読取・点圧表示・解析・Excel出力へ回帰を起こさないこと

## 6. 技術的考慮事項（参考）

> このセクションは壁打ち時点のメモです。詳細設計は `/add-feature` 実行時に `steering/design.md` として生成されます。

### 実装アプローチ（案）
- 状態変数:
  - `swatch_toggle_on`（既存）を継続利用
  - `scaling_toggle_on`（新規）を追加
- 表示更新関数:
  - `update_iromihon_button_visual(...)` を「色ベース」へ変更
  - `update_scaling_button_visual(...)` を新規追加
- スケーリング処理:
  - `set_conversion_factor()` 開始時にON化
  - 完了/キャンセル/再押下キャンセルでOFF化
  - OFF時は `canvas` のイベントバインドを通常へ戻す

### 色変更の実現方法
- 優先: 既存のON/OFF画像アセットで明確に色差を付ける
- 補助: 必要に応じて `ttk.Style` の `foreground` / `background` 差分を併用
- 注記: OSテーマ依存で `ttk.Button` 背景色が効きにくい環境があるため、画像差分を第一手段とする
- 暫定色: ON中の色は `RGB(155,253,155)` を基準に作成する

## 7. 受け入れ条件

- [ ] `標準色見本処理` ボタンに `：ON / ：OFF` が表示されない
- [ ] 標準色見本ボタンはON中のみ色が変わる
- [ ] `スケーリング` ボタンもON中のみ色が変わる
- [ ] スケーリング完了/キャンセル時にOFF色へ戻る
- [ ] 既存の色見本読取・スケーリング係数設定・通常解析フローに回帰がない
- [ ] 文字化けが発生しない
