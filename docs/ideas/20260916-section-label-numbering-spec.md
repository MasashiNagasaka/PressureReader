# セクションラベル先頭の番号付与 仕様書

> 作成日: 2026-09-16
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

右ペインの各セクション見出しに通し番号を付与し、操作順序を直感的に分かりやすくする。

## 2. スコープ

### 今回含めるもの
- 右ペインのセクション見出しテキスト先頭に、上から順に `①`〜`⑦` を付与する。
- 表示順と番号の対応を固定する。
- 既存のセクション機能・処理ロジックは変更しない。

### 今回含めないもの（将来対応）
- セクションの並び順変更
- ボタン配置・レイアウト構造の再設計
- 英語表記や多言語対応

## 3. ユーザーストーリー

- ユーザーとして、操作手順を迷わないために、画面上のセクションが番号付きで順番に並んでほしい。

## 4. 機能要件

### 4.1 ラベル文言の変更
- [ ] `画像準備：` を `①画像準備：` に変更する
- [ ] `解析条件：` を `②解析条件：` に変更する
- [ ] `範囲選択形状：` を `③範囲選択形状：` に変更する
- [ ] `選択範囲の検出値（MPa）：` を `④選択範囲の検出値（MPa）：` に変更する
- [ ] `出力：` を `⑤出力：` に変更する
- [ ] `入力内容クリア：` を `⑥入力内容クリア：` に変更する
- [ ] `お問い合わせ：` を `⑦お問い合わせ：` に変更する

### 4.2 表記ルール
- [ ] 番号文字は `①②③④⑤⑥⑦`（丸数字）を使用する
- [ ] 番号とラベル本文の間に半角/全角スペースは入れない（例: `①画像準備：`）
- [ ] 既存フォント・スタイル（`Custom.TLabel`）は維持する

### 4.3 ラベルサイズ・レイアウト調整
- [ ] 文言変更後のラベル表示で、文字欠け・省略表示・折返しが発生しないこと
- [ ] 必要に応じて、各セクションラベルの `padx` / `pady` / `columnspan` / `sticky` を調整する
- [ ] ラベル調整によって、配下のボタン・入力欄との縦間隔が不自然にならないこと
- [ ] 右ペイン全体の横幅ルール（既存の統一感）を維持すること

## 5. 非機能要件

- 可読性: 既存UIに対してラベルが欠けないこと
- 保守性: 変更対象はラベル文言定義箇所に限定する
- 互換性: 既存機能動作（ボタン押下、入力、出力、問い合わせダイアログ表示）に影響を与えないこと

## 6. 技術的考慮事項（参考）

> このセクションは壁打ち時点のメモです。詳細設計は `/add-feature` 実行時に `steering/design.md` として生成されます。

### 実装アプローチ（案）
- `src/PressureReader.py` の右ペイン見出し `ttk.Label(..., style="Custom.TLabel")` の `text` を置換する。
- 文字幅不足が出る場合は、ラベル単位で `grid(...)` の余白・張り付き設定を最小限調整する（大規模なレイアウト変更はしない）。
- ラベル生成位置（現状の目安）:
  - `画像準備：` 付近
  - `解析条件：` 付近
  - `範囲選択形状：` 付近
  - `選択範囲の検出値（MPa）：` 付近
  - `出力：` 付近
  - `入力内容クリア：` 付近
  - `お問い合わせ：` 付近

### 既存コードへの影響（想定）
- 変更: `src/PressureReader.py`（ラベルテキスト定義のみ）
- 追加: なし

### 注意点・リスク
- 丸数字は文字化けリスクがあるため、UTF-8で保存し、編集時に再エンコードしないこと。
- レイアウト幅が厳しい箇所で見切れが発生しないか、実機で表示確認すること。

## 7. 受け入れ条件

- [ ] 右ペイン見出しが上から `①`〜`⑦` の順で表示される
- [ ] 各見出し文言が本仕様の表記と完全一致する
- [ ] すべての対象ラベルで文字欠け・折返し・見切れがない
- [ ] 既存ボタン動作・解析・出力・問い合わせ表示に回帰がない
- [ ] 文字化け（?表示、豆腐、異体字崩れ）が発生しない
