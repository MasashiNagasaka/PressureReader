# 検出値セクションラベル（単位明記）仕様書

> 作成日: 2026-09-11
> ステータス: Draft
> 用途: `/add-feature` 実装用

---

## 1. 背景・目的
- 検出値セクション全体の単位をラベルで明示し、ユーザーが値の意味を一目で理解できるようにする。

---

## 2. スコープ

### 2.1 対象
- 検出値セクションの見出しラベル（現在: `選択範囲の検出値：`）

### 2.2 非対象
- `検出値（平均）` / `検出値（最大）` / `検出値（最小）` の文言
- 各行の `MPa` ラベル
- 検出値の計算/表示ロジック
- レイアウト（位置、サイズ、余白）

---

## 3. 仕様

### 3.1 文言変更
- セクションラベルを以下へ変更する。

変更前:
- `選択範囲の検出値：`

変更後:
- `選択範囲の検出値（MPa）：`

### 3.2 表示維持
- ラベル位置は現状維持。
- ラベル文字サイズ・フォントは現状維持。
- 他UI要素の並び順や余白は変更しない。

---

## 4. 受け入れ基準
- [ ] セクションラベルが `選択範囲の検出値（MPa）：` になっている
- [ ] ラベル位置が変更されていない
- [ ] ラベル文字サイズ・フォントが変更されていない
- [ ] 検出値の表示内容（数値 / `測定範囲外`）に回帰がない
- [ ] 文字化けが発生していない

---

  - `label_ken`（検出値セクション見出し）文言定義
