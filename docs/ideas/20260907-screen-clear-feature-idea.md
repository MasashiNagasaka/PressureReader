# アイディアメモ: 作業やり直し用の画面クリア機能

## 要望
- 一から作業をやり直す際の画面クリア機能がほしい。

## 背景
- 解析途中で範囲選択や表示結果、入力値をまとめて初期化したい場面がある。
- 現在の操作では状態の一括リセットが分かりにくく、やり直し時の手間が発生する。

## 期待する動作（案）
- 1クリックで「作業開始前に近い状態」に戻せる。
- 少なくとも以下をクリア対象にできること:
  - キャンバス上の選択範囲（矩形/多角形/円）
  - 計算結果表示（検出値、面積表示、マーク表示）
  - 必要に応じて解析条件入力値（運用に合わせて範囲を決める）

## 補足
- 詳細仕様（どこまで初期化するか、確認ダイアログ有無）は別途To-Beで詰める。
