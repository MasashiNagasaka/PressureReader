# 画面クリア機能 仕様書

> 作成日: 2026-09-07
> ステータス: Draft
> 用途: `/add-feature` への入力

---

## 1. 背景・目的

PressReaderでは解析途中に「最初からやり直したい」場面が多いが、現状は状態の一括初期化が不十分で、操作コストと誤操作リスクがある。  
特に既存の`clear_selectarea()`は、矩形モード時に`set_mode_rect()`を引数なしで呼ぶため実行時エラーが発生し得る。

本改修では、**1操作で安全に作業状態をリセットできる画面クリア機能**を定義する。  
あわせて、操作入口として**`画面リセット`ボタン**を新設する。

本仕様の`画面リセット`は、従来の「選択範囲だけを消す」操作ではなく、**Python実行直後の初期状態（As-Started）**へ戻すことを目的とする。

---

## 2. スコープ

### 今回含めるもの
- 既存「選択範囲クリア」操作の安定化（実行時エラー回避）
- 「作業やり直し」のための画面リセット仕様の明確化と実装
- クリア後の既定状態（モード、表示、結果欄、解析条件欄）の統一
- 画面リセット押下時の確認メッセージ表示（誤操作防止）
- 解析条件入力の初期化（明度、温度、湿度、スケーリング）
- プレスケール種別の初期化（`LLW 持続圧`）
- 測定範囲可視化状態の初期化（OFF）
- 読み込み画像状態の初期化（画像未選択状態）
- 右側ボタンエリア最下段への`画面リセット`ボタン追加

### 今回含めないもの（将来対応）
- 初期化対象のカスタマイズ（「画像は残す」「解析条件は残す」等のチェック式設定）
- 新しい永続設定ファイルの導入

---

## 3. ユーザーストーリー

- 解析担当者として、途中状態を一度に消して初期状態に戻したい。そうすることで、再作業を素早く正確に開始できる。
- 解析担当者として、クリア操作でエラー停止せず、常に同じ初期状態に戻ってほしい。

---

## 4. 機能要件

### 4.1 クリア対象（必須）
- [ ] キャンバス上の選択範囲を削除する（矩形/多角形/円）
- [ ] 選択範囲由来の補助表示を削除する（面積テキスト、マーク、補助線）
- [ ] 計算結果表示をクリアする（`atai_ave_entry`）
- [ ] 範囲選択モードを既定値へ戻す（四角形モード）
- [ ] 内部選択状態を再初期化する（多角形点列、円ハンドル状態、ドラッグ状態）
- [ ] 解析条件入力欄をクリアする（明度13欄、温度、湿度、`pixmm`）
- [ ] プレスケール種別を初期値へ戻す（`selected_var = "LLW 持続圧"`）
- [ ] 測定範囲可視化をOFFに戻す（表示テキスト・アイコン・内部フラグ）
- [ ] 換算係数を初期化する（`conversion_factor = None`）
- [ ] 読み込み画像と関連状態を初期化し、未読込状態へ戻す（`image_with_metadata` 等）

### 4.2 クリア後の状態（必須）
- [ ] `mode = "rect"` であること
- [ ] `current_value = "99"`（通常測定モード）であること
- [ ] 次のドラッグ操作で直ちに新規範囲選択できること
- [ ] `selected_var = "LLW 持続圧"` であること
- [ ] 明度入力欄（表示対象）は空欄であること
- [ ] `ondo_entry`、`shitsudo_entry`、`pixmm_entry` が空欄であること
- [ ] `atai_ave_entry` が空欄であること
- [ ] `apply_threshold_flag = False` であり、ボタン表示が`測定範囲可視化：OFF`であること
- [ ] キャンバスに画像タグ`image`が存在せず、未読込警告ロジックが有効に動作すること

### 4.3 エラーハンドリング（必須）
- [ ] 画像未読込状態でクリア操作しても例外を出さないこと
- [ ] 既に選択範囲が無い状態でクリア操作しても例外を出さないこと
- [ ] 解析条件が空欄でも、リセット処理内で`float()`例外を出さないこと
- [ ] 連打（3回以上）しても同一状態を維持し、例外を出さないこと

### 4.4 既存UIとの整合（必須）
- [ ] 既存の範囲選択ラジオボタン（矩形/多角形/円）と矛盾しないこと
- [ ] 既存のプレスケール選択UI（OptionMenu）と矛盾しないこと
- [ ] 既存の測定範囲可視化トグルUIと矛盾しないこと

### 4.5 `画面リセット`ボタン仕様（必須）
- [ ] ボタン名は`画面リセット`とすること
- [ ] ボタン配置は右側ボタンエリアの**最下段**とすること
- [ ] ボタンサイズ、フォント、余白、配置方法は既存ボタンの実装パターンに合わせること
- [ ] ボタン表示アイコンは以下の画像を使用すること:
  - `C:\nagasaka\AI\PressureReader\Project01\src\pr_images\reset_window.png`
- [ ] ボタン表示は**アイコン＋テキスト**とし、テキストは`画面リセット`とすること
- [ ] クリック時に確認メッセージを表示し、ユーザー承認時のみ本仕様4.1〜4.3のリセット処理を実行すること

### 4.6 確認メッセージ仕様（必須）
- [ ] `画面リセット`押下時にモーダル確認ダイアログを表示すること
- [ ] ダイアログ文言は、少なくとも「現在の作業状態が初期化される」ことが分かる文面にすること
- [ ] ダイアログは`実行`（または`OK`）と`キャンセル`の2択であること
- [ ] `キャンセル`選択時は、画面状態・入力値・内部状態を一切変更しないこと
- [ ] `実行`選択時のみ、画面リセット処理を開始すること
- [ ] ダイアログを閉じる（×ボタン）操作は`キャンセル`と同等に扱うこと
- [ ] 確認ダイアログ表示中は多重起動しないこと（連打で複数ダイアログを開かない）

---

## 5. 非機能要件

- パフォーマンス: クリア操作は体感即時（通常PC環境で0.2秒以内を目安）
- 信頼性: 連続実行（10回以上）でも例外が発生しない
- 保守性: クリア処理は単一責務で整理し、モード初期化との責務を明確化する

---

## 6. 技術的考慮事項（参考）

> このセクションは壁打ち時点のメモ。詳細設計は`/add-feature`で確定する。

### 実装アプローチ（案）
- 既存`clear_selectarea()`を「画面状態クリア関数」として再定義する。
- `reset_to_startup_state()`（仮名）を用意し、以下の順に初期化する:
  1. 描画要素・選択内部状態の解除
  2. 解析条件入力欄のクリア
  3. OptionMenu/ラジオ/可視化トグルの初期値復帰
  4. 画像関連変数の解除とキャンバス再描画
- 矩形モード復帰は必ず`set_mode_rect("99")`を使い、引数欠落を排除する。
- 必要に応じて、描画要素クリアと状態変数クリアを関数分割して読みやすくする。
- 新設する`画面リセット`ボタンの`command`は、上記クリア関数を呼ぶ構成にする。

### 既存コードへの影響（想定）
- 変更: `src/PressReader_v3.4.2.py`（改名後は`src/PressReader_v3.5.0.py`）
  - `clear_selectarea()`
  - `set_mode_rect()`呼び出し箇所
  - ボタン定義の最下段追加（アイコン読込・`ttk.Button`定義・hover処理）
  - 必要に応じて関連する初期化変数周辺

### 注意点・リスク
- 既存の`標準色見本処理`（`set_mode_rect("14")`）への影響を避けること
- メタデータ未読込画像で明度欄が空のケースでもリセットが安全に完了するようにすること
- リセット時に`load_image()`を再利用するとファイルダイアログが開くため、UI非介入で初期化できる実装にすること
- 確認ダイアログ追加により操作ステップが1つ増えるため、文言は短く明確にすること
- `選択範囲クリア`ボタンには確認ダイアログを適用しない（誤操作リスクが高い`画面リセット`のみ対象）
- 版上げ改修（v3.5.0化）と衝突しないよう、対象ファイル名の差異に注意する

## 7. 受け入れ条件

- [ ] `画面リセット`ボタンが右側ボタンエリア最下段に表示される
- [ ] `画面リセット`ボタンに`reset_window.png`が表示される
- [ ] `画面リセット`ボタンにテキスト`画面リセット`が表示される（アイコンと併記）
- [ ] `画面リセット`押下で例外（TypeError/NameError等）が発生しない
- [ ] `画面リセット`押下時に確認メッセージが表示される
- [ ] 確認メッセージで`キャンセル`した場合、画面状態が押下前から変化しない
- [ ] 確認メッセージで`実行`した場合のみリセットが実施される
- [ ] 矩形モード中に押下しても正常にクリアされる
- [ ] 多角形モード中に押下しても頂点・ポリゴンが消え、再選択できる
- [ ] 円形モード中に押下しても円・ハンドルが消え、再選択できる
- [ ] クリア後、検出値欄が空欄になる
- [ ] クリア後、四角形モードで新規範囲選択が可能である
- [ ] クリア後、プレスケール選択が`LLW 持続圧`になる
- [ ] クリア後、明度・温度・湿度・スケーリング欄が空欄になる
- [ ] クリア後、測定範囲可視化がOFF表示になる
- [ ] クリア後、画像未選択状態となり、キャンバス操作時に未読込ガードが機能する
