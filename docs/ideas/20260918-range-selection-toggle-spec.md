# 範囲選択トグル追加と状態明確化 仕様書

> 作成日: 2026-09-18  
> ステータス: Draft  
> 用途: /add-feature への入力

---

## 1. 背景・目的

範囲選択機能（四角形/多角形/円形）の「有効・無効」と「形状選択」の関係が分かりづらい。  
範囲選択のON/OFFを独立したトグルで明示し、現在状態を見てすぐ判別できるようにする。

## 2. スコープ

### 今回含めるもの
- ラベル文言変更
- 新規トグルボタン「範囲選択」追加
- 範囲選択ON/OFFでのラジオボタン表示切替
- ステータスバー文言連動

### 今回含めないもの
- 四角形/多角形/円形それぞれの解析ロジック変更
- 既存の標準色見本処理・スケーリング処理ロジック変更

## 3. 機能要件

### 3.1 ラベル変更
- [ ] セクションラベルを以下へ変更する。  
  - 変更前: `③範囲選択形状：`  
  - 変更後: `③範囲選択：`

### 3.2 新規トグルボタン
- [ ] ラベル `③範囲選択：` の直下に新規トグルボタン `範囲選択` を追加する。
- [ ] ON/OFFのボタン色は、既存トグル（標準色見本処理・スケーリング）と同じルールを使う。
  - ON色: `#9BFD9B`
  - OFF色: 既存ボタン標準色
- [ ] 起動直後の初期状態は `OFF` とする。

### 3.3 ON時の挙動
- [ ] `範囲選択` が ON のとき、以下ラジオボタンを表示する。
  - `四角形モード`
  - `多角形モード`
  - `円形モード`
- [ ] ステータスバーに `モード：範囲選択` を表示する。
- [ ] OFF中に残っていた既存図形があっても、ONへ戻した時点では自動クリアしない。

### 3.4 OFF時の挙動
- [ ] `範囲選択` が OFF のとき、上記3つのラジオボタンを非表示にする。
- [ ] ステータスバーの `モード：範囲選択` 表示を解除する。
- [ ] OFFへ切替えても、既存の選択図形はクリアせず表示を維持する。
- [ ] OFFへ切替え後も、既存図形に対する編集操作（ドラッグ移動・ハンドルドラッグによる形状変更）は可能とする。

### 3.6 旧図形クリアのタイミング
- [ ] 既存図形が残った状態で範囲選択ONに戻した後、ユーザーが新規範囲選択図形を作成した時点で旧図形をクリアする。
- [ ] 旧図形クリアは「新規図形作成が成立したタイミング」で実行し、ON切替だけでは実行しない。

### 3.5 ステータスバー優先順位（既存との整合）
- [ ] 既存優先順位は維持する（標準色見本 > スケーリング > 範囲選択）。
- [ ] `範囲選択` が OFF の場合は、`mode` が `rect/polygon/circle` でも範囲選択文言は表示しない。
- [ ] 文言は以下を採用する。
  - 標準色見本: `モード：標準色見本の選択`
  - スケーリング: `モード：スケーリングの設定`
  - 範囲選択: `モード：範囲選択`

## 4. 非機能要件

- 可読性: 範囲選択が有効かどうかをボタン状態で即判別できること
- 一貫性: 既存トグルの見た目・色規則と統一すること
- 安定性: 既存解析処理、Excel出力、他モード挙動に回帰を起こさないこと

## 5. 実装メモ（案）

- 新規状態変数:
  - `range_select_toggle_on = tk.BooleanVar(value=False)`（初期OFF）
- 新規関数:
  - `update_range_select_button_visual()`
  - `toggle_range_selection_mode()`
  - `apply_range_select_visibility()`（ラジオ3種の `grid()` / `grid_remove()` 制御）
- 既存関数調整:
  - `update_mode_status_bar()` に `range_select_toggle_on` 判定を追加
  - `set_mode_rect/polygon/circle` からの更新順を維持
- レイアウト:
  - 既存ラジオボタンの行番号は維持または最小調整し、他セクションと重なりを出さない

## 6. 受け入れ条件

- [ ] ラベルが `③範囲選択：` に変更されている
- [ ] `範囲選択` トグルが追加され、ON/OFFで色が変わる
- [ ] ONでモードラジオ3種が表示される
- [ ] OFFでモードラジオ3種が非表示になる
- [ ] ONでステータスバーに `モード：範囲選択` が表示される
- [ ] OFFでステータスバーの `モード：範囲選択` が消える
- [ ] OFF切替え後も、既存選択図形は残る
- [ ] OFF切替え後も、既存図形の移動・ハンドル操作で編集できる
- [ ] ONへ戻しただけでは既存図形は消えない
- [ ] 新規範囲選択図形を作成した時点で旧図形がクリアされる
- [ ] 既存の標準色見本/スケーリング/解析/出力に回帰がない
- [ ] 文字化けが発生しない

## 7. 原因分析と対策（今回の不具合）

### 7.1 原因
- `on_mouse_down` 冒頭で `範囲選択=OFF` の場合に新規作成を抑止しているため、
  標準色見本処理（`current_value=="14"`）の矩形選択開始までブロックされる。
- その結果、標準色見本処理ボタン押下後に画像をクリックしても何も置けない。

### 7.2 対策
- `範囲選択OFF` の新規作成抑止条件に例外を追加する。
  - 標準色見本処理中（`current_value=="14"`）は抑止しない。
  - 必要に応じてスケーリング中も抑止対象外にする。
- 受け入れ確認に以下を追加する。
  - `範囲選択OFF` でも、標準色見本処理ボタン押下後の矩形選択は可能。
  - 一方で通常の範囲選択新規作成は `範囲選択ON` の時だけ可能。

### 7.3 追加不具合（モードOFF時の点圧非表示）
- 現象:
  - 標準色見本処理OFF、スケーリングOFF、範囲選択OFFの状態で画像クリックしても点圧が表示されない。
- 原因:
  - `on_mouse_down` の `範囲選択OFF` 分岐で、`mode=rect/current_value=99` が早期returnし、
    クリック点圧表示の処理に到達しない。
- 対策:
  - 早期return前に「3モードすべてOFF時のクリック点圧表示」分岐を置く。
  - そのうえで新規範囲作成の抑止は従来どおり維持する。

## 8. 点圧・面積表示ルール（追記）

### 8.1 点圧表示
- 標準色見本処理モード中のクリックでは点圧を表示しない。
- スケーリングモード中のクリックでは点圧を表示しない。
- 範囲選択モード中の選択途中クリックでは点圧を表示しない。
- 範囲の確定操作クリックでは点圧を表示しない。
- 範囲確定後の通常クリックでは点圧を表示してよい。
- 標準色見本処理/スケーリング/範囲選択のすべてがOFFのときは、画像クリックで点圧を表示してよい。

### 8.2 面積表示
- 標準色見本処理モード中は面積表示しない。
- スケーリングモード中は面積表示しない。
- 範囲選択モード中の選択途中は面積表示しない。
- 面積表示は範囲確定後のみとする。
