# 範囲確定前の点圧表示（クリック1点）仕様書

> 作成日: 2026-09-14
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- 現在は範囲選択を確定しないと、選択位置の圧力値を直感的に確認しづらい。
- ユーザーが画像上を1点クリックした時点で、その点の圧力検出値(MPa)を表示できるようにし、操作途中でも判断しやすくする。

---

## 2. スコープ

### 今回含めるもの
- 1点クリック時の圧力表示（範囲確定前プレビュー）
- 四角形/円形/多角形モードでの「範囲確定前 = 点圧表示」挙動
- 範囲確定後は既存の範囲統計表示（平均/最大/最小）へ復帰

### 今回含めないもの
- 圧力換算ロジック（`c2p`）の変更
- 検出値UIレイアウトの変更
- 高圧検出箇所マーク処理の仕様変更

---

## 3. 機能要件

### 3.1 点クリック時の表示
- [ ] 画像上を1点クリックした時、その点の圧力値(MPa)を表示する。
- [ ] 表示先は検出値欄ではなく、画像上のクリック点の上側にする。
- [ ] 表示形式は面積表示テキストと同系統のキャンバステキスト表示にする（例: `0.123MPa`）。
- [ ] `点圧` の固定テキストは表示しない。
- [ ] 点圧表示は一時表示とし、次のクリックや範囲確定時に更新/置換される。

### 3.2 四角形モード
- [ ] マウスダウン直後（ドラッグ開始前）はクリック点の圧力を表示する。
- [ ] ドラッグして範囲確定（マウスアップ）後は、既存どおり範囲の平均/最大/最小を表示する。

### 3.3 円形モード
- [ ] マウスダウン直後（半径が確定する前）はクリック点の圧力を表示する。
- [ ] 円形確定後（既存フロー）に範囲の平均/最大/最小表示へ切り替える。

### 3.4 多角形モード
- [ ] 左クリックで頂点を追加するたびに、そのクリック点の圧力を表示する。
- [ ] 多角形モードでは各頂点ごとに、各点の上側へ個別に圧力を表示する。
- [ ] 右クリックで多角形確定するまでは、範囲統計ではなく点圧表示を優先する。
- [ ] 右クリックで多角形確定後は、既存どおり範囲の平均/最大/最小を表示する。

### 3.5 ガード条件
- [ ] 既存の解析条件未設定ガード（明度/温湿度など）は維持する。
- [ ] 画像未読込時は既存ガードを維持する。

---

## 4. 技術的考慮事項（参考）

- 追加候補関数:
  - `calculate_point_pressure(canvas_x, canvas_y)`  
    - キャンバス座標 -> 元画像座標へ変換
    - 輝度1点を `c2p` で圧力へ変換
    - 有効範囲外の場合は既存ルールに準じて `None` もしくは閾値扱い
  - `show_point_pressure_text(canvas_x, canvas_y, pressure_value)`
    - キャンバス上の点の上側へ `xx.xxxMPa` を表示
    - 範囲確定表示（面積テキスト）と競合しないタグ管理を行う
  - `show_polygon_point_pressure_text(point_index, canvas_x, canvas_y, pressure_value)`
    - 多角形の各頂点に対して個別テキストを表示
    - 頂点ごとの更新/削除ができるタグ管理を行う
- 更新対象の主処理:
  - `on_mouse_down`（四角形/円形で点圧プレビュー）
  - `on_mouse_down`（多角形の頂点追加時にも点圧プレビュー）
  - `on_mouse_up` / `right_click`（既存範囲統計表示のまま）

---

## 5. 受け入れ条件

- [ ] 四角形モードでクリック直後に、画像上のクリック点の上側へ圧力値が表示される。
- [ ] 円形モードでクリック直後に、画像上のクリック点の上側へ圧力値が表示される。
- [ ] 多角形モードで各頂点クリック時に、各点の上側へ圧力値が個別表示される。
- [ ] 四角形/円形/多角形いずれも範囲確定後は既存の平均/最大/最小表示になる。
- [ ] 既存ガード（画像未読込、解析条件不足）に回帰がない。
- [ ] 文字化けが発生していない。
