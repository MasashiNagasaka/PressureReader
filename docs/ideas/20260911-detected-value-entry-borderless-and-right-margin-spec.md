# 検出値表示欄の枠線除去と右端重なり解消 仕様書

> 作成日: 2026-09-11
> ステータス: Draft
> 用途: `/add-feature` 実装用

---

## 1. 背景・目的
- `検出値（平均）` / `検出値（最大）` / `検出値（最小）` の値表示欄について、枠線が不要。
- 値表示欄と `MPa` の右側が画面右端に近すぎて見づらいため、右端との余白を確保したい。
- 現在はスクロールバー表示時のみ見え方が改善し、スクロールバー非表示時に右端へ重なって見える。

---

## 2. スコープ

### 2.1 対象
- 右パネルの検出値表示エリア（`detected_value_frame`）内の3つの値表示欄。
- 同エリアの右側余白（画面右端との距離）。

### 2.2 非対象
- 検出値の計算ロジック（平均/最大/最小）
- ラベル文言、ラベル位置、ラベル文字サイズ
- クリア処理や保存処理などの動作ロジック

---

## 3. 仕様

### 3.1 値表示欄の枠線を削除
- `検出値（平均）` / `検出値（最大）` / `検出値（最小）` の値表示欄は、枠線なし表示にする。
- 値の文字色・背景色・フォントは現行の視認性を維持する。
- `focus` 時にも外枠が強調されないようにする（不要な強調枠を出さない）。

### 3.2 右端余白の確保
- 検出値表示エリアの右側に余白を追加し、右端と重なって見える状態を解消する。
- 右端余白は、`MPa` 表示が視覚的に詰まらない最小限の量とする。
- 既存の上下レイアウト順（操作フロー）は変更しない。
- スクロールバー表示有無のどちらでも、同じ見え方（右端非重なり）を保証する。

### 3.3 動作維持
- 値更新（数値表示 / `測定範囲外`）の動作は変更しない。
- 画面リセット、選択範囲クリア、画像読み込み時のクリア動作に回帰を出さない。

---

## 4. 技術的考慮事項（参考）
> 詳細設計は `/add-feature` 実行時に確定。

- 対象箇所は `src/PressureReader.py` の `detected_value_frame` 周辺。
- 現状は `tk.Entry(..., relief="solid", bd=1)` で枠線ありのため、フラット表示へ切替える。
- 現状の重なりは、スクロールバー非表示時に `button_canvas` の有効幅が広がることによる相対位置差が一因。
- 右端余白は、`detected_value_frame` の右 `padx`、`columnconfigure` の余白列、または `MPa` ラベル側余白の組み合わせで、スクロールバー有無に依存しない形で確保する。
- 変更は検出値エリア限定で行い、他の入力欄に影響を与えない。

---

## 5. 受け入れ基準
- [ ] 3つの値表示欄の枠線が表示されない
- [ ] 値表示欄をクリック（フォーカス）しても不要な強調枠が出ない
- [ ] 値表示欄の右横が画面右端と重ならず、視認性が改善している
- [ ] スクロールバー表示時/非表示時の両方で、右端と重ならない
- [ ] ラベル文言・ラベル位置・ラベル文字サイズに変更がない
- [ ] 検出値の表示内容（数値 / `測定範囲外`）に回帰がない
- [ ] 文字化けが発生していない
