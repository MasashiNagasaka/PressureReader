# スケーリング単位ラベル（mm/px）表示欠け修正 仕様書

> 作成日: 2026-09-11
> ステータス: Draft
> 用途: `/add-feature` 実装用

---

## 1. 背景・目的
- 現在、スケーリング行の単位ラベルが `mm/px` ではなく `mm` のみ見えることがある。
- 現在、`mm/` までしか表示されず、末尾の `px` が欠けるケースがある。
- 現在、`pixmm_entry` の右に不自然な大きい空白があり、`mm/px` を直右に表示できていない。
- 単位が欠けると解釈を誤るため、常に `mm/px` が完全表示されるようにする。

---

## 2. スコープ

### 2.1 対象
- スケーリング行（`ｽｹｰﾘﾝｸﾞ` ボタン + `pixmm_entry` + `mm/px` ラベル）

### 2.2 非対象
- スケーリング計算ロジック
- スケーリングダイアログの入力仕様
- 検出値/Excel出力のロジック

---

## 3. 仕様

### 3.1 単位ラベルの完全表示
- スケーリング行の単位ラベル `mm/px` が、常に文字欠けなく表示されること。
- `mm` のみ、`mm/` のみなど、末尾欠けの状態を解消すること。

### 3.2 レイアウト調整（最小差分）
- スケーリング行の横幅配分を最小限調整する。
  - `pixmm_entry` の右横に `mm/px` を**直近配置**する（大きい空白を作らない）
  - `pixmm_entry` の `padx` と単位ラベルの `padx` を最小化する
  - 列の固定幅（`minsize` など）で空白を作る方式は使わない
  - 必要なら `pixmm_entry` の横幅を再調整して表示領域を確保する
- 既存の操作フローと行順は維持する。

### 3.3 既存動作維持
- `ｽｹｰﾘﾝｸﾞ` ボタン位置は変更しない。
- `pixmm_entry` の値表示/設定動作は変更しない。
- スクロールバー表示有無で見え方が崩れないこと。

---

## 4. 技術的考慮事項（参考）
> 詳細設計は `/add-feature` 実行時に確定。

- 現状は `pixmm_entry width=10` と `label_pixmm_unit text=\"mm/px\"` の横並びで、右端余白条件により `px` が欠ける可能性がある。
- 対象箇所:
  - `src/PressureReader.py` の `button_pixmm` / `pixmm_entry` / `label_pixmm_unit` 定義周辺。
- `pixmm_entry` と `mm/px` の間に大きい空白を生む設定（列固定幅、過大な `padx`）を排除する。
- 単位ラベルは `pixmm_entry` のすぐ右横に置き、必要最小限の間隔（例: 0〜2px程度）にする。
- 変更はスケーリング行限定とし、他行のレイアウトへ波及させない。

---

## 5. 受け入れ基準
- [ ] スケーリング行で `mm/px` が全文字表示される
- [ ] `mm/` で欠ける状態が解消される
- [ ] `pixmm_entry` の直右に `mm/px` が表示される（不自然な大きい空白がない）
- [ ] スクロールバー表示時/非表示時の両方で `mm/px` が欠けない
- [ ] `ｽｹｰﾘﾝｸﾞ` ボタン位置が変更されていない
- [ ] `pixmm_entry` の入力・表示が従来どおり動作する
- [ ] 文字化けが発生していない
