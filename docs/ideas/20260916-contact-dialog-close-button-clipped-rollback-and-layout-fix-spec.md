# 問い合わせ先ダイアログ: 閉じるボタン潰れ悪化の是正仕様

> 作成日: 2026-09-16  
> ステータス: Draft  
> 用途: /add-feature への入力

---

## 1. 事象

- 問い合わせ先ダイアログ下部の `閉じる` ボタンが完全に潰れて押せない。
- 直前の `padding` / `pady` 調整で改善せず、表示悪化が発生した。

---

## 2. 原因仮説

- ダイアログ全高が固定比率（`screen_height/1080`）で決まり、実フォント/DPIで下部余白不足になっている。
- 本文領域（`content_frame`）が優先して高さを消費し、`閉じる` が押しつぶされる。

---

## 3. 対策方針

### 3.1 直前調整の巻き戻し

- `close_button` の `padding` と `pady` 追加は一旦戻す（悪化要因除去）。

### 3.2 レイアウト構造の修正（本命）

- `閉じる` を本文フレームの外に独立した `footer_frame` で配置する。
  - `footer_frame` を `pack(side=BOTTOM, fill=X)`。
  - `content_frame` は `pack(fill=BOTH, expand=True)` のまま。
- これにより本文の伸縮と `閉じる` 領域を分離し、潰れを防ぐ。

### 3.3 最低高さの安全弁

- `dialog_height` に最小値を設ける（例: `max(int(470 * scale), 500)`）。
- 必要なら `update_idletasks()` 後に `winfo_reqheight()` を見て不足時に再設定する。

---

## 4. 受け入れ条件

- [ ] `閉じる` ボタンが完全表示され、クリック可能。
- [ ] 125%/150% スケール環境でもボタンが潰れない。
- [ ] 問い合わせ本文・コピー機能に回帰がない。

---

## 5. NG時のフォールバック

- 最終手段として `dialog_height` を固定で増やす（+60〜100px）。
- ただし構造修正（3.2）を優先し、単純な余白調整だけで終わらせない。
