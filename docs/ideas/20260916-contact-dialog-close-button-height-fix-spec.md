# 問い合わせ先ダイアログ: 閉じるボタン縦幅つぶれ修正 仕様書

> 作成日: 2026-09-16
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景

問い合わせ先ボタンで表示するダイアログ下部の `閉じる` ボタンが縦につぶれて表示される場合があり、押しづらい。

---

## 2. 目的

- `閉じる` ボタンの高さを確保し、クリックしやすい状態にする。
- 既存の問い合わせ先表示内容・コピー機能には影響を出さない。

---

## 3. 要件

1. `閉じる` ボタンの縦方向サイズを明示的に確保する。
2. 下部の余白不足でボタンが圧縮されないようにする。
3. 既存レイアウト（ヘッダ、本文、コピー行）は維持する。

---

## 4. 仕様詳細

### 4.1 ボタンの高さ確保

- `close_button` に `padding` を設定して縦サイズを確保する。
  - 例: `padding=(10, 4)` 相当
- 必要に応じて `width` は維持し、文字中央配置のままにする。

### 4.2 下部余白の調整

- `body_frame` / `close_button.pack(...)` の `pady` を見直し、
  ボタンの上下に十分な空きが出るようにする。
- ダイアログ全体高さが不足する場合は `dialog_height` を最小限拡大する。

---

## 5. 受け入れ条件

- [ ] 問い合わせ先ダイアログの `閉じる` ボタンが縦につぶれない。
- [ ] マウスで押しやすい高さになっている。
- [ ] 既存の `コピー` ボタン動作に回帰がない。
