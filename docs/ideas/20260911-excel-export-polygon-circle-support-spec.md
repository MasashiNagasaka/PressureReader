# 選択範囲Excel出力: 多角形/円形モード対応 仕様書

> 作成日: 2026-09-11
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- 現在の `選択範囲Excel出力` は実質的に四角形モードのみ対応している。
- 多角形モード/円形モードで解析できていても、Excel出力できないため運用上の制約になっている。
- 既存の選択モード（四角形・多角形・円形）のいずれでも、同じ出力操作でExcel保存できるようにする。

---

## 2. 現状整理（コード調査）

- 出力関数: `save_brightness_to_xlsx()`
- 現状の制約:
  - `no_rect()` で `canvas` の `"rect"` タグ存在を必須化している（四角形以外は弾かれる）
  - 出力領域計算が `start_x/start_y/end_x/end_y` の矩形切り出し前提
- 一方で既存コードには:
  - 多角形マスク生成（`calculate_brightness2`）
  - 円形マスク生成（`calculate_brightness3`）
  が実装済みで、流用可能。

---

## 3. スコープ

### 今回含めるもの
- `選択範囲Excel出力` の3モード対応（四角形/多角形/円形）
- モードごとの有効選択判定
- モードごとの出力対象マスク生成

### 今回含めないもの
- Excelフォーマット（セルサイズ・ファイル名ルール）の変更
- 圧力換算ロジック（`c2p`）の変更
- 画面表示UIの大幅変更

---

## 4. 機能要件

### 4.1 選択判定
- [ ] 四角形モード: 既存どおり矩形選択があることを確認
- [ ] 多角形モード: `polygon_points` と `polygon_id` の確定状態を確認
- [ ] 円形モード: `circle_id` と半径情報の確定状態を確認
- [ ] いずれのモードでも未選択時は既存メッセージ `選択範囲を作成してください` を表示

### 4.2 出力領域
- [ ] 四角形: 既存の矩形切り出しを継続
- [ ] 多角形: 画像座標へ変換したポリゴンマスクを作成し、マスク内のみ値を出力
- [ ] 円形: 画像座標へ変換した楕円マスクを作成し、マスク内のみ値を出力
- [ ] マスク外は `None`（空欄）として出力する

### 4.3 出力データ
- [ ] 値変換は現状ルールを維持
  - `press_Min`〜`press_Max`: 圧力値（小数）
  - `press_Max` 超過: `999`
  - `press_Min` 未満かつ `white_Press` より上: `-999`
  - それ以外: 空欄
- [ ] 保存ダイアログキャンセル時は何も保存せず復帰

---

## 5. 技術的方針（参考）

- 追加ヘルパー例:
  - `has_valid_selection_for_export(mode, ...)`
  - `build_export_gray_and_mask(mode, ...)`
- マスク作成は既存の座標変換ロジック（`offset_x/offset_y/scale/inv_scale`）に合わせる。
- Excel書き込み処理は既存を再利用し、`converted_region` の作り方のみモード対応にする。

---

## 6. 受け入れ条件

- [ ] 四角形モードで従来どおりExcel出力できる（回帰なし）
- [ ] 多角形モードで選択範囲をExcel出力できる
- [ ] 円形モードで選択範囲をExcel出力できる
- [ ] 各モードで選択外は空欄となる
- [ ] スケーリング未設定時ガードは従来どおり動作する
- [ ] 文字化けが発生していない
