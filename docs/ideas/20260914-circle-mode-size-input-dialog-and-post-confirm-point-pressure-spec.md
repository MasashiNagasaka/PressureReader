# 円形モードのサイズ入力ダイアログ化と確定後点圧表示 仕様書

> 作成日: 2026-09-14
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- 現在の円形モードは、クリック後のドラッグでサイズを決める操作であり、狙ったサイズを数値で再現しにくい。
- ユーザー要望として、中心点クリック後にサイズを入力して円を確定したい。
- あわせて、サイズ入力が完了するまでは点圧表示を出さず、選択確定後のクリックで点圧表示する流れに整理したい。

---

## 2. スコープ

### 今回含めるもの
- 円形モードで中心点クリック後にサイズ入力ダイアログを表示する。
- ダイアログUIはスケーリング入力ダイアログ（`custom_askfloat`）に準拠した見た目・挙動にする。
- 入力欄の隣に単位表示を追加する。
- 入力完了・円形確定後のクリックで点圧表示を行う。
- 入力完了前（ダイアログ表示中/未確定）は、円形モードのクリックで点圧表示を行わない。

### 今回含めないもの（将来対応）
- 四角形モード/多角形モードの操作変更
- 圧力換算ロジック（`c2p`）の変更
- 右クリック時の真円化仕様変更

---

## 3. ユーザーストーリー

- 解析担当者として、円の中心をクリックしたあとに数値でサイズを入力して、再現性のある円選択を行いたい。
- 解析担当者として、選択確定後は任意点クリックで点圧を確認したい。

---

## 4. 単位切替方針（mm/px）

### 結論
- 入力欄右の単位は **スケーリング設定状態で自動切替**する。
  - `mm/px` 設定済み: `mm`
  - `mm/px` 未設定: `px`

### 切替理由
- スケーリング設定済みなら実寸（mm）入力の方が業務上の再現性が高い。
- 未設定時は変換不能のため、画素基準（px）入力が最も自然。
- 自動切替により、ユーザーの前提知識や手動切替操作を減らせる。

### 表示ルール
- 入力値は「半径」とする。
- 入力単位が `mm` の場合は `px = mm / (mm/px)` で内部変換して描画する。
- 円サイズ表示（円周辺のテキスト表示）は入力単位に合わせて表示する。
  - `mm` モード: `半径 xx.xxxmm`
  - `px` モード: `半径 xx.xxxpx`

---

## 5. 機能要件

### 5.1 円形サイズ入力フロー
- [ ] 円形モードで画像上をクリックしたら、その点を中心候補としてサイズ入力ダイアログを開く。
- [ ] ダイアログで `半径[単位]` を入力し、OK時に円を作成して確定する。
- [ ] 入力値が無効（空/数値でない/0以下）の場合はエラーメッセージを表示し、再入力を促す。
- [ ] ダイアログをキャンセルした場合は円を作成しない。

### 5.2 ダイアログUI（スケーリング準拠）
- [ ] `Toplevel` のモーダルダイアログ（`grab_set`, `wait_window`）とする。
- [ ] スケーリング入力ダイアログと同等のレイアウト・サイズ感・アイコン設定を踏襲する。
- [ ] 入力欄の右側に単位ラベルを表示し、スケーリング設定状態で `mm` / `px` を自動切替する。

### 5.3 円サイズ表示（単位連動）
- [ ] 円のサイズ表示は入力単位に連動させる。
- [ ] `mm` 入力時は `mm` 表示、`px` 入力時は `px` 表示とする。
- [ ] 表示値は入力値基準（半径）を使用し、内部計算用の `px` 変換値とは区別する。

### 5.4 点圧表示のタイミング
- [ ] サイズ入力完了前（未確定）は、円形モードのクリック時点圧表示を行わない。
- [ ] 円確定後は、既存ルールどおり通常クリックで点圧表示、ドラッグ発生時は編集操作優先とする。

### 5.5 既存挙動維持
- [ ] 円内部ドラッグ移動、ハンドルドラッグ編集は従来どおり可能。
- [ ] 円確定後の範囲再計算（平均/最大/最小・高圧検出マーク）は従来どおり。

---

## 6. 非機能要件

- パフォーマンス: ダイアログ表示と円描画は体感遅延なく実行されること。
- 信頼性: ダイアログキャンセル/不正入力で例外を発生させないこと。
- 一貫性: スケーリングダイアログと同等のUIパターンで学習コストを増やさないこと。

---

## 7. 技術的考慮事項（参考）

> このセクションは壁打ち時点のメモです。詳細設計は `/add-feature` 実行時に `steering/design.md` として生成されます。

### 実装アプローチ（案）
- `set_conversion_factor` 内 `custom_askfloat` に準じた円形用入力ダイアログ関数を追加（共通化も可）。
- `on_mouse_down` の `mode == "circle"` 新規作成導線を
  - クリック座標取得
  - スケーリング状態を判定して単位（mm/px）を決定
  - ダイアログで半径入力（単位付き）
  - 入力成功時に必要なら `mm -> px` 変換し `center_x/center_y/radius_x/radius_y` を設定
  - `update_circle()` 実行
  へ変更する。
- 右クリック確定/`on_mouse_up` の既存分岐と二重確定にならないよう、確定状態フラグ（または既存 `drawing_circle` の扱い）を調整する。
- 円サイズ表示文字列を単位連動で更新する（`text` タグまたは専用タグ）。

### 既存コードへの影響（想定）
- 変更: `src/PressureReader.py`
  - `on_mouse_down`（circle分岐）
  - 必要に応じて円形入力ダイアログ関数追加
  - `on_mouse_up`（新規ドラッグ作成フロー縮退に伴う分岐整理）
- 参照:
  - `set_conversion_factor` 内 `custom_askfloat`
  - `update_circle`, `calculate_brightness3`

### 注意点・リスク
- 既存の「クリックしてドラッグで作図」フローと混在すると状態遷移が複雑化するため、円新規作成は入力ダイアログ経由へ一本化する。
- キャンセル時の状態（`circle_id`, `drawing_circle`, 一時変数）を必ず無変更に戻す。

## 8. 受け入れ条件

- [ ] 円形モードで中心クリック時にサイズ入力ダイアログが開く。
- [ ] ダイアログはスケーリング入力ダイアログに近い見た目で、入力欄右の単位が `mm` / `px` で自動切替される。
- [ ] スケーリング設定済みでは `半径[mm]` 入力で円が確定作成される。
- [ ] スケーリング未設定では `半径[px]` 入力で円が確定作成される。
- [ ] 不正入力時は確定せず、再入力を促す。
- [ ] キャンセル時は円を作成しない。
- [ ] 入力完了前は点圧表示されない。
- [ ] 円サイズ表示が入力単位に連動して `mm` / `px` で表示される。
- [ ] 円確定後クリックで点圧表示される。
- [ ] 円内部移動・ハンドル編集・範囲再計算に回帰がない。
- [ ] 文字化けが発生していない。
