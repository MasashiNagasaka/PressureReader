# 多角形頂点ハンドルとテキストの非接触マージン 仕様書

> 作成日: 2026-09-17
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

多角形モードで点圧テキストを表示した際、頂点ハンドル（シアンの丸）とテキストが「重なりはしないが接触する」ケースがあり、視認性が悪い。  
頂点ハンドルとテキストの間に最低限の余白を保証し、見やすさを改善する。

### 再現ケース（今回の具体例）
- 多角形をひし形状にしたとき、一番上の頂点ハンドル付近で点圧テキストが表示される。
- テキスト左端が頂点ハンドルに食い込み、ぎりぎり重なる。
- 既存のBBox拡張のみではこのケースを取り切れないため、点圧ラベルの基準オフセットと最終補正の両方を強化する。
- 面積テキスト（`選択範囲面積 ... / 有効測定範囲面積 ...`）でも、2行目先頭の「有」が頂点ハンドルに重なる。
- 多角形の形状によっては「有」以外の文字（1行目・2行目の任意文字）も重なる。
- 共通点として、多角形確定時に「多角形の最上頂点ハンドル」と面積テキストが接触する。

### 既存対策が効かなかった理由（再整理）
- 対応頂点1点のみの離隔補正では、他頂点ハンドルとの接触を防ぎきれない。
- 「重なり面積最小」評価は、接触ぎりぎり（距離ほぼ0）を許してしまう。
- 候補位置の再評価後に、最小距離制約を全ハンドルに対して強制していない。
- 点圧テキスト向けの補正を追加しても、面積テキスト側の配置ロジックには同等の距離制約が入っていない。
- 面積テキストの配置基準が第1頂点依存のため、最上頂点が第1頂点付近になる形状で再発しやすい。

## 2. スコープ

### 今回含めるもの
- 多角形モードにおける頂点ハンドルとテキストの非接触マージン制御
- 多角形の各頂点点圧ラベル、および多角形面積テキストの配置調整

### 今回含めないもの
- 四角形/円形モードの仕様変更
- フォント、色、サイズの変更
- 圧力計算やExcel出力ロジックの変更

## 3. 機能要件

### 3.1 非接触マージン
- [ ] 多角形頂点ハンドルを回避対象として扱う。
- [ ] 回避判定時、頂点ハンドルBBoxを外側へ拡張して評価する（安全余白）。
- [ ] 余白値は固定ピクセルで実装し、現状6pxからの拡大を許容する（例: 10〜12px）。

### 3.1.1 頂点点圧テキスト専用オフセット（改訂）
- [ ] 多角形「各頂点」の点圧テキスト第一候補を現状より右へ広げる（例: `+8px → +20px`）。
- [ ] 最小離隔は「対応頂点だけでなく全頂点ハンドル」に対して保証する。
- [ ] 制約は水平のみではなく、BBox間の最短距離（ユークリッド距離）で判定する。
- [ ] 最短距離が閾値未満（例: 4px）なら、候補は不採用とする。

### 3.2 配置判定
- [ ] 「重なり面積ゼロ」だけでなく、「最小距離が余白未満」もNGとする。
- [ ] 候補位置（上→右→左→下）の評価順は維持する。
- [ ] 候補がすべてNGの場合は、右方向へ段階シフト（例: 4px刻み、最大40px）して再評価する。
- [ ] それでもNGなら、最小距離が最大となる位置を採用し、接触ゼロを優先する。

### 3.3 対象表示
- [ ] 多角形の各頂点点圧テキストに適用する。
- [ ] 多角形面積テキスト（第1頂点基準表示）にも同じ余白ルールを適用する。

### 3.4 多角形面積テキストの専用要件（今回重点）
- [ ] 面積テキスト（2行表示）に対して、全頂点ハンドルとの最短距離制約（例: 6px以上）を適用する。
- [ ] 候補位置（上→右→左→下）評価時、距離条件を満たさない候補は不採用とする。
- [ ] すべて不採用なら、右方向・下方向へ段階シフトして再評価する。
- [ ] 2行目先頭文字（「有」）が頂点ハンドルに接触しないことを必須条件とする。

### 3.5 最上頂点ハンドル回避ルール（追加）
- [ ] 多角形確定後、頂点群から `y` 最小の最上頂点ハンドルを特定する。
- [ ] 面積テキストは「最上頂点ハンドルの上側禁止領域」を侵さない位置に配置する。
- [ ] 禁止領域は「最上頂点ハンドルBBox + 安全マージン」で定義する。
- [ ] 文字単位ではなく、テキスト全体BBoxで接触判定する（任意文字重なりを防ぐ）。

## 4. 非機能要件

- 可読性: 頂点ハンドルとテキストが接触しないこと。
- 一貫性: 既存の重なり回避ロジック思想を維持したまま最小差分で実装すること。
- 安定性: ドラッグ移動中・確定後の再描画でちらつきや残像が出ないこと。

## 5. 技術メモ（実装時の指針）

- 回避BBox収集処理に「頂点ハンドル」の識別タグを含める。
- 頂点ハンドルBBoxの `padding` は6px固定ではなく調整可能値とし、ひし形上頂点ケースで再チューニングする。
- 多角形頂点点圧テキストでは、候補座標を「上側優先」のまま右オフセットを増やす。
- 最終配置前に「全頂点ハンドルBBoxとの最短距離チェック」を追加する。
- 位置決定を `重なり面積` だけでなく `最短距離` を含むスコアで評価する。
- 多角形面積テキストにも同じ最短距離評価を適用し、点圧テキストとの差をなくす。
- 面積テキストの基準点は「第1頂点固定」ではなく「多角形外接BBoxの上中央または右上」を優先候補にする。
- 最上頂点ハンドルを基準にした禁止領域チェックを最終判定に含める。
- 既存ヘルパーの拡張で対応し、計算処理・表示タグ運用（`point_pressure` / `text`）は維持する。

## 6. 受け入れ条件

- [ ] 多角形モードで、頂点ハンドルと点圧テキストが接触しない
- [ ] 多角形モードで、頂点ハンドルと面積テキストが接触しない
- [ ] ひし形の最上頂点で、テキスト左端がハンドルに重ならない
- [ ] ひし形の最上頂点で、面積テキスト2行目先頭「有」がハンドルに重ならない
- [ ] ひし形の最上頂点で、面積テキストの任意文字がハンドルに重ならない
- [ ] ひし形・三角形・細長い多角形の各ケースで、全頂点ハンドルとテキストが非接触
- [ ] 頂点ドラッグ中・多角形全体ドラッグ中でも上記を維持
- [ ] 圧力値表示内容、圧力計算、Excel出力結果に影響がない
- [ ] 文字化けが発生しない
