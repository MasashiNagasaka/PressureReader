# スケーリング行改修のレイアウト回帰修正 仕様書

> 作成日: 2026-09-11
> ステータス: Draft
> 用途: `/add-feature` 実装用

---

## 1. 背景・目的
- スケーリング行の `mm/px` 直右表示は改善したが、その変更により以下のレイアウト回帰が発生している。
  - 色見本の各 Entry とラベルが右側へ大きくずれる
  - 温度/湿度の各 Entry が右側へ大きくずれる
- 右側ずれを解消し、スケーリング行改善と既存UI整列を両立する。

---

## 2. スコープ

### 2.1 対象
- 右パネル内レイアウト（特に次の行）
  - 色見本ラベル/Entry行（row 7〜14 相当）
  - 温度/湿度行（row 15〜16）
  - スケーリング行（row 17）

### 2.2 非対象
- 圧力換算ロジック
- Excel出力ロジック
- 検出値の統計ロジック

---

## 3. 仕様

### 3.1 回帰解消（最優先）
- 色見本 Entry/ラベル、および温度/湿度 Entry を、改修前と同等の左寄せ位置へ戻す。
- 「右側へ大きくずれる」状態を解消する。

### 3.2 スケーリング行の改善は維持
- `pixmm_entry` の値（例: `0.017614`）が欠けないこと。
- `mm/px` が `pixmm_entry` の直右に表示されること。

### 3.3 レイアウト実装方針
- 右パネルの基準グリッドに影響を与える設定を見直し、スケーリング行だけで閉じる調整にする。
- 必要に応じて、スケーリング行を「内部フレーム + 内部配置」で扱うが、外側グリッド列の幅計算へ副作用を出さないこと。
- 既存行（色見本・温湿度）の `grid` 定義値（column, padx, sticky）を基準値として維持する。

### 3.4 既存動作維持
- `ｽｹｰﾘﾝｸﾞ` ボタンの機能は維持。
- `pixmm_entry` の設定/読込/リセット動作は維持。
- スクロールバー表示時/非表示時の両方でレイアウトが崩れないこと。

---

## 4. 技術的考慮事項（参考）
> 詳細設計は `/add-feature` 実行時に確定。

- 右側ずれは、スケーリング行改修時のレイアウト管理（フレーム構成、grid/pack併用、余白設定）による列計算への副作用が疑われる。
- 検証時は「改修前基準位置」と比較し、色見本/温湿度/スケーリングの3領域を同時確認する。
- 変更はレイアウト定義に限定し、機能ロジックには触れない。

---

## 5. 受け入れ基準
- [ ] 色見本の各Entryとラベルが右側へ大きくずれていない
- [ ] 温度/湿度の各Entryが右側へ大きくずれていない
- [ ] `pixmm_entry` で `0.017614` が欠けずに表示される
- [ ] `mm/px` が `pixmm_entry` の直右に表示される
- [ ] スクロールバー表示時/非表示時の両方で上記を満たす
- [ ] 既存機能（スケーリング設定、メタ復元、画面リセット）に回帰がない
- [ ] 文字化けが発生していない
