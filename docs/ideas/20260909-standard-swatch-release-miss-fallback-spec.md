# 標準色見本処理後の自動クリア不発対策（リリース取りこぼし対応）仕様書

> 作成日: 2026-09-09
> ステータス: Draft
> 用途: `/add-feature` 実装入力

---

## 1. 背景・目的

現在コード上は、標準色見本処理（`current_value == "14"`）の矩形選択完了時に
`clear_selectarea()` を呼ぶ実装になっている。

それでも実動作で「矩形選択後に選択範囲クリアが実行されない」事象があるため、
`on_mouse_up` が発火しない経路（マウスアップのイベント取りこぼし）を考慮した対策が必要。

目的は、**標準色見本処理の完了時に通常モード復帰を必ず成立させる**こと。

---

## 2. 原因仮説（plan-kaizen）

- `clear_selectarea()` 自体の処理は成立している（手動ボタン押下で復帰可能）。
- 不発の主因は、`canvas` 上の `<ButtonRelease-1>` が発火しないケース（例: ドラッグ終了位置がキャンバス外）。
- 現在の復帰処理は `on_mouse_up` 依存のため、イベント取りこぼし時に復帰処理へ到達しない。

---

## 3. スコープ

### 3.1 実施すること
- 標準色見本処理の終了判定を `canvas` の `on_mouse_up` 依存から、グローバルなリリース検知でも補完する。
- 復帰処理を1箇所の関数に集約し、`on_mouse_up` とフォールバック双方から呼ぶ。

### 3.2 実施しないこと
- 標準色見本の採色アルゴリズム変更。
- 多角形/円モードの操作変更。
- 圧力算出ロジック変更。

---

## 4. 仕様

### 4.1 復帰処理の共通化
- [ ] `finalize_standard_swatch_selection()`（仮名）を新設。
- [ ] 本関数内で `clear_selectarea()` を実行し、通常矩形モードへ復帰。
- [ ] 復帰対象条件は `mode == "rect" and current_value == "14"`。

### 4.2 既存経路
- [ ] `on_mouse_up` の `current_value == "14"` 分岐から共通関数を呼ぶ。

### 4.3 フォールバック経路（取りこぼし対策）
- [ ] `root.bind("<ButtonRelease-1>", on_global_mouse_up, add="+")` を追加。
- [ ] `on_global_mouse_up` では、以下条件を満たす場合のみ共通関数を呼ぶ:
- [ ] `mode == "rect"`
- [ ] `current_value == "14"`
- [ ] `rect_selected == True`（選択途中）
- [ ] 必要に応じて座標をキャンバス内へクリップして `on_mouse_up` 相当処理へ委譲、または直接共通関数実行。

### 4.4 多重実行防止
- [ ] 同一操作で `on_mouse_up` と `on_global_mouse_up` が重複発火しても1回だけ復帰するようガードする。

---

## 5. 受け入れ条件

- [ ] 標準色見本処理で、キャンバス内でマウスアップした場合に通常モードへ復帰する。
- [ ] キャンバス外でマウスアップした場合でも通常モードへ復帰する。
- [ ] 復帰時に選択範囲表示はクリアされる。
- [ ] 追加で `選択範囲クリア` ボタンを手動押下しなくても作業継続できる。
- [ ] 通常四角形解析（`current_value == "99"`）に副作用がない。

---

## 6. 実装メモ（/add-feature 引き継ぎ）

### 6.1 変更対象（想定）
- `src/PressureReader.py`

### 6.2 変更ポイント（想定）
- `on_mouse_up`
- `clear_selectarea` 呼び出し周辺
- 新規 `on_global_mouse_up`
- 末尾バインド設定（`root.bind`）

### 6.3 注意点
- 既存のスケーリング操作で `canvas.bind("<ButtonRelease-1>", on_mouse_up)` を再設定しているため、
  グローバルフォールバックは `root` 側で常時有効にする。

---

## 7. テスト観点

- 標準ケース: キャンバス内リリースで復帰。
- 取りこぼしケース: キャンバス外リリースで復帰。
- 連続操作: 標準色見本処理を連続で実施しても固着しない。
- 回帰確認: 四角形/多角形/円の通常操作に影響しない。
