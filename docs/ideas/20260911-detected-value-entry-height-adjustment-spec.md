# 検出値表示欄の縦幅微調整 仕様書

> 作成日: 2026-09-11
> ステータス: Draft
> 用途: `/add-feature` 実装用

---

## 1. 背景・目的
- `検出値（平均）` / `検出値（最大）` / `検出値（最小）` の右横にある値表示欄が、縦方向にくっついて見える。
- 視認性を改善するため、表示欄の縦幅を少しだけ小さくする。

---

## 2. スコープ

### 2.1 対象
- 右パネルの検出値表示エリア内にある、3つの値表示欄（Entry）
  - 平均値表示欄
  - 最大値表示欄
  - 最小値表示欄

### 2.2 非対象
- ラベル文言の変更
- ラベル位置の変更
- ラベル文字サイズの変更
- 検出値の計算ロジック（平均/最大/最小）変更
- 単位 `MPa` 表示の変更

---

## 3. 仕様

### 3.1 表示欄の縦幅調整
- 3つの値表示欄の縦幅を、現状より少しだけ小さくする。
- 調整量は「視認上くっついて見えない」最小限にする（過度な縮小はしない）。

### 3.2 レイアウト維持
- ラベル位置は現状維持とする。
- ラベル文字サイズは現状維持とする。
- 各行の左右位置関係（ラベル / 値表示欄 / `MPa`）は現状維持とする。

### 3.3 動作維持
- 値の更新動作（平均/最大/最小、`測定範囲外` 含む）は変更しない。
- 選択範囲クリアや画面リセット時のクリア動作は変更しない。

---

## 4. 技術的考慮事項（参考）
> 詳細設計は `/add-feature` 実行時に確定。

- 対象箇所は `src/PressureReader.py` の `detected_value_frame` 周辺。
- Entry高さはテーマ依存があるため、既存見た目を崩さない方法で最小差分で調整する。
- 既存の共通スタイルへの影響を避け、検出値エリア限定での変更を優先する。

---

## 5. 受け入れ基準
- [ ] `検出値（平均）` / `検出値（最大）` / `検出値（最小）` の値表示欄が、従来よりわずかに低く表示される
- [ ] 3つの値表示欄が、縦方向にくっついて見えない
- [ ] ラベル位置が変更されていない
- [ ] ラベル文字サイズが変更されていない
- [ ] 検出値の計算・表示ロジック（数値、`測定範囲外`）に回帰がない
- [ ] 文字化けが発生していない
