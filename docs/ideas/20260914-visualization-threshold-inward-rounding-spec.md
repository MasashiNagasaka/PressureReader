# 可視化しきい値の境界安定化（端点クランプ）

## 背景
- 選択範囲可視化ONで、標準色見本の端点（1.0 / 0.1）が外れ判定されることがある。
- `gray` は整数画素値のため、境界付近の判定揺れが発生しやすい。

## 目的
- 標準色見本の端点を「測定範囲内」として安定的に扱う。
- 可視化の反応性を保ち、色変化が極端に弱くならないようにする。

## 仕様
- しきい値は固定マージン `1` を使用する。
  - `low_threshold = floor(bri_Max) - 1`
  - `high_threshold = ceil(bri_Min) + 1`
- 端点クランプを適用する。
  - 上側端点（1.0）: `low_threshold <= floor(top_min)` を保証
  - 下側端点（0.1）: `high_threshold >= ceil(bottom_max)` を保証
- `top_min` / `bottom_max` は、色見本ごとの `filtered` 画素から算出した最小値/最大値を使う。
- 色見本のエントリー表示値は従来どおり `filtered` の平均値を使う。

## 非対象
- 可視化色（黄/緑）とマスク条件（`<` / `>`）の変更は行わない。
- 圧力換算・Excel出力ロジックには影響させない。
