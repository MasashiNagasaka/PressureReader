# 起動時スプラッシュ2（info案内ウィンドウ）追加 仕様書

> 作成日: 2026-09-11
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- 起動時に、ユーザーへ事前準備物を明確に案内したい。
- 現在は `スプラッシュ1 → メイン` の2段階遷移であり、準備物の案内が起動導線に含まれていない。
- 起動導線を `スプラッシュ1 → スプラッシュ2（案内）→ メイン` に変更する。

---

## 2. スコープ

### 今回含めるもの
- 起動時表示順の変更:
  - `スプラッシュ1（既存画像）`
  - `スプラッシュ2（追加のinfo案内ウィンドウ）`
  - `メイン画面`
- スプラッシュ2の表示時間:
  - 8秒（8000ms）で自動クローズ
- スプラッシュ2の表示文言:
  - 本アプリ使用時は、事前に下記を準備して下さい。
  - ・画像PDF　…　感圧紙  および  標準色見本
  - ・温度[℃]、湿度[%]　…圧力計測時の値
  - ・スケール　…感圧紙の寸法[mm]
- メッセージのフォントサイズを既存メッセージより大きめにする。

### 今回含めないもの
- メイン画面のUI変更
- 解析ロジック変更
- PDF/PNG/Excel機能変更

---

## 3. ユーザーストーリー

- ユーザーとして、アプリ起動直後に必要な準備物を確認してから作業を始めたい。
- ユーザーとして、読みやすい大きめ文字で案内を見たい。

---

## 4. 機能要件

### 4.1 起動シーケンス
- [ ] 起動時に `スプラッシュ1 → スプラッシュ2 → メイン` の順で表示される。
- [ ] スプラッシュ2表示中はメイン画面を表示しない。

### 4.2 スプラッシュ2（info案内ウィンドウ）
- [ ] 8秒表示後に自動で閉じる。
- [ ] タイトルは `事前準備` にする。
- [ ] 表示文言は以下を改変せず表示する:

```
本アプリ使用時は、事前に下記を準備して下さい。
・画像PDF　…　感圧紙  および  標準色見本
・温度[℃]、湿度[%]　…圧力計測時の値
・スケール　…感圧紙の寸法[mm]
```

### 4.3 フォントサイズ
- [ ] スプラッシュ2の本文フォントは `("Meiryo ui", 14)` を使用する（boldは使用しない）。

### 4.4 強調表示（文字色・太字）
- [ ] 下記キーワードのみ、**マゼンダ色 + bold** で強調表示する。
  - 2行目: `画像PDF`、`感圧紙`、`標準色見本`
  - 3行目: `温度[℃]`、`湿度[%]`、`圧力計測時の値`
  - 4行目: `スケール`、`寸法[mm]`
- [ ] 強調以外の本文は通常色・通常ウェイトを維持する。

### 4.5 各行の `…` 位置揃え
- [ ] 2行目〜4行目の `…`（説明区切り記号）は、縦位置を揃えて表示する。
- [ ] 目視で揃うことを優先し、全角空白の手打ち調整には依存しない。
- [ ] 実装時は以下いずれかの方式で揃える:
  - 左カラム（項目名） + 右カラム（説明）の2カラムレイアウト
  - または、等幅幅のラベル領域を用いた疑似カラムレイアウト
- [ ] 表示テキストは次を基準とする:
  - `・画像PDF　　　　　 …感圧紙  および  標準色見本`
  - `・温度[℃]、湿度[%]　…圧力計測時の値`
  - `・スケール　　　　　…感圧紙の寸法[mm]`

## 5. 技術的考慮事項（参考）

### 5.1 実装方式
- `messagebox.showinfo(...)` はフォントサイズ制御が難しいため、**info用途の専用 `Toplevel` ウィンドウ**で実装する。
- 見た目は info案内用途（タイトル・本文・背景色）に合わせる。
- 部分強調（キーワードのみ色・太字）を行うため、本文は1ラベル固定ではなく、行/語単位で分割表示する。

### 5.2 時間設定の定数化
- 表示時間は将来調整しやすいよう定数化する。
  - 例:
    - `SPLASH1_DURATION_MS = 2000`
    - `SPLASH2_DURATION_MS = 8000`

### 5.3 既存挙動維持
- 既存スプラッシュ1（画像 + バージョン表示）の仕様は維持する。
- メイン画面タイトル・各機能の挙動には影響を与えない。

## 6. 受け入れ条件

- [ ] 起動時に `スプラッシュ1 → スプラッシュ2 → メイン` の順で遷移する
- [ ] スプラッシュ2が8秒表示される
- [ ] スプラッシュ2の文言が指定どおり表示される
- [ ] タイトルが `事前準備` で表示される
- [ ] スプラッシュ2本文が `("Meiryo ui", 14)`（boldなし）で表示される
- [ ] 指定キーワードのみマゼンダ色 + bold で強調表示される
- [ ] 3行の `…` 位置が縦に揃って表示される
- [ ] 既存のスプラッシュ1表示とメイン画面起動に回帰がない
- [ ] 文字化けが発生していない
