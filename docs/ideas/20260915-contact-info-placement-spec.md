# アプリ問い合わせ先表示仕様（改訂）

> 作成日: 2026-09-15  
> ステータス: 合意済み（レイアウト改訂）

---

## 1. 背景

問い合わせ先ダイアログで、ユーザーが触る必要のない説明文は固定表示にし、  
コピー操作が必要なメールアドレスの近くに `コピー` ボタンを配置して使いやすくする。

---

## 2. 合意仕様

- 右ペインの `お問い合わせ：` セクションと `問い合わせ先` ボタンは維持する。
- 問い合わせ先ダイアログ内の次の部分は、**ユーザーが触らなくてよい固定表示**とする。
  - `■アプリ問い合わせ先`
  - `メールまたはTeamsにてご連絡下さい。`
- 以下の2ブロックで、担当者名の**すぐ下**にメールアドレス行と `コピー` ボタンを配置する。
- メールアドレス行のテキスト左端は、直上の担当者名行の左端に揃える（インデント量を一致させる）。

### ブロック1（アプリについて）
- `計測・デジタル基盤改革部`
- `アプリについて`
- `電動化デジタル開発室 Nagasaka, Masashi/長坂 政史`
- その直下: `mail：masashi_nagasaka_zd@mail.toyota.co.jp` + `コピー` ボタン（左端は担当者名行と揃える）

### ブロック2（計測相談・依頼）
- `計測相談・依頼`
- `計測・デジタル課 Suzuki, Kota/鈴木 宏太`
- その直下: `mail：kota_suzuki_ab@mail.toyota.co.jp` + `コピー` ボタン（左端は担当者名行と揃える）

---

## 3. 補足要件

- 最低限、担当者名行（
  `電動化デジタル開発室 Nagasaka, Masashi/長坂 政史` /  
  `計測・デジタル課 Suzuki, Kota/鈴木 宏太`
  ）は選択不可でも許容する。
- ただし、メールアドレスはコピーしやすい配置を優先する。

---

## 4. 実装方針（次工程）

- `messagebox` は使用せず、専用 `Toplevel` ダイアログで表示する。
- 固定文と担当者名は `Label` 中心で表示する。
- メールアドレスは各担当者ブロックの直下に配置し、右側に `コピー` ボタンを置く。
- メールアドレス `Label` の配置開始位置（left/start）は、対応する担当者名 `Label` の配置開始位置と一致させる。
- `コピー` 押下時は該当メールアドレスをクリップボードへ入れる。
