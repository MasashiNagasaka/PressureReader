# Excel出力セルの緑・黄・赤カラースケール仕様書

> 作成日: 2026-09-14
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- Excel出力後の圧力分布を、数値だけでなく色でも直感的に把握したい。
- 出力したセル全体に条件付き書式のカラースケールを適用し、低値/中間値/高値の傾向を一目で確認できるようにする。

## 2. スコープ

### 今回含めるもの
- `save_brightness_to_xlsx` で生成する出力セル範囲全体に、条件付き書式（緑・黄・赤の3色スケール）を付与する。
- 対象範囲は Excel 出力したデータ領域（`A1` から最終セル）とする。
- 既存のズーム自動調整、セル寸法設定、保存処理は維持する。

### 今回含めないもの（将来対応）
- カラースケール色のユーザー設定（色変更UI）
- 条件付き書式の種類切替（データバー、アイコンセット）
- 除外値（例: `999` / `-999`）の個別色付けルール追加

## 3. ユーザーストーリー

- 解析担当者として、Excel出力結果を開いたときに圧力分布を色で素早く把握したい。
- 解析担当者として、既存の出力フロー（保存操作）はそのままに、色付きで確認効率を上げたい。

## 4. 機能要件

### 4.1 条件付き書式の適用
- [ ] Excel出力範囲（`row_count` × `col_count`）が1セル以上ある場合、条件付き書式を設定する。
- [ ] 対象範囲を `A1:{最終列}{最終行}` として算出する。
- [ ] 3色カラースケール（低: 緑 / 中央: 黄 / 高: 赤）を適用する。

### 4.2 既存挙動維持
- [ ] 既存の値出力（`None`は空欄）を変更しない。
- [ ] 既存の列幅・行高さ設定を変更しない。
- [ ] 既存のズーム自動調整（`zoomScale`）を変更しない。
- [ ] 既存の保存成功/失敗メッセージ表示を変更しない。

## 5. 非機能要件

- パフォーマンス: 条件付き書式追加による体感遅延を最小限にする（通常操作で待ち時間増を感じないこと）。
- 保守性: 既存の `save_brightness_to_xlsx` の責務を大きく崩さず、追加箇所を明確化する。
- 互換性: 既存 Python 環境・既存パッケージ（`openpyxl`）のみで実現する。

## 6. 技術的考慮事項（参考）

> このセクションは壁打ち時点のメモです。詳細設計は `/add-feature` 実行時に `steering/design.md` として生成されます。

### 実装アプローチ（案）
- `openpyxl.formatting.rule.ColorScaleRule` を利用して、3色スケールを設定する。
- 例:
  - 開始点: `type='min'`, `color='00B050'`（緑）
  - 中央点: `type='percentile'`, `val=50`, `color='FFFF00'`（黄）
  - 終了点: `type='max'`, `color='FF0000'`（赤）
- `ws.conditional_formatting.add(range_ref, rule)` を使用する。

### 既存コードへの影響（想定）
- 変更: `src/PressureReader.py`
  - `save_brightness_to_xlsx` 内の Excel 出力ブロック（保存前）に条件付き書式付与を追加
- 変更: `.steering/20260914-excel-auto-zoom-fit-output-range/`（必要時）
  - 既存Excel出力関連ステアリングとの整合メモ更新

### 注意点・リスク
- 空欄セル（`None`）は評価対象外になるため、色はつかない想定。
- `999` / `-999` が分布端として強く効く可能性がある（本仕様では出力全体適用を優先し、そのまま対象に含める）。
- Excel表示テーマやユーザー環境により、色の見え方はわずかに差が出る可能性がある。

## 7. 受け入れ条件

- [ ] Excel出力後、データ領域全体に緑・黄・赤の3色カラースケールが設定される。
- [ ] 低値セルほど緑寄り、高値セルほど赤寄り、中間値は黄寄りで表示される。
- [ ] 空欄セルは従来どおり空欄表示のまま（不要な値埋めなし）。
- [ ] 既存のExcel出力（値・セル寸法・ズーム・保存メッセージ）に回帰がない。
- [ ] 既存Pythonパッケージのみで実装可能である。
- [ ] 文字化けが発生していない。
