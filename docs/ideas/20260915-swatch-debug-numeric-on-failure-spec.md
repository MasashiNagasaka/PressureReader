# 標準色見本デバッグ表示: 失敗時も数値を出力する 仕様書

> 作成日: 2026-09-15
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景

現状の標準色見本デバッグ表示では、取得失敗した明度キーが `None (failed)` と表示される。  
ユーザー要望は、成功/失敗にかかわらず、デバッグ表示を常に数値で確認できること。

---

## 2. 目的

- デバッグログ上で `None` 表示をなくし、全キーを数値で確認可能にする。
- 既存のUI状態（`読取失敗` 表示）や処理判定（成功/失敗ロジック）は維持する。

---

## 3. 要件

1. 標準色見本処理後の各キー出力について、失敗キーでも数値を出すこと。
2. `None (failed)` のログ文言は廃止すること。
3. 成功/失敗の判定そのものは変更しないこと。
4. 既存のエントリー反映仕様（失敗時は空欄）とステータス表示は維持すること。

---

## 4. 仕様詳細

### 4.1 ログ出力ルール

- 成功キー:
  - 現行どおり、取得した平均明度を小数2桁で表示する。
- 失敗キー:
  - デバッグ表示専用の補完値 `debug_fallback_value` を表示する。
  - 表示例:  
    `[DEBUG] swatch brightness 0.1 = 187.42 (failed-fallback)`

### 4.2 失敗時の補完値

- `debug_fallback_value` は、標準色見本選択ROI全体の平均明度（`roi_mean`）を使用する。
- 理由:
  - 常に算出可能で、選択範囲の実測値として妥当。
  - `None` を避けつつ、固定値（0や-1）より意味がある。

### 4.3 非対象

- 失敗キーを成功扱いにする変更。
- 失敗時エントリーに補完値を書き戻す変更。
- 圧力換算ロジック、CSV設定、Excel出力への影響。

---

## 5. 受け入れ条件

- [ ] 失敗キーがあるケースで、`None (failed)` がログに出ない。
- [ ] 失敗キーのログが数値表示になる（`(failed-fallback)` 付き）。
- [ ] 成功キーのログ数値は従来どおり出る。
- [ ] UIの失敗表示（`読取失敗(やり直し)`）は従来どおり。

---

## 6. 実装メモ（PressureReader.py）

- 変更対象:
  - `insert_to_visible_entries(...)` の失敗ログ出力
  - `value_key == "14"` の採色処理内で算出済み `roi_mean` の受け渡し
- 受け渡し方式案:
  - `insert_to_visible_entries(avg_list, bounds_list=None, debug_fallback_value=None)`
  - 失敗時ログで `debug_fallback_value` を使用
