# 範囲選択図形とテキストの重なり回避 仕様書

> 作成日: 2026-09-17
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

四角形/多角形/円形の選択範囲を表示した際に、圧力値や面積などのテキストが図形線・点マーカーと重なり、視認性が低下する。  
図形とテキストが重ならない表示ルールを導入し、読みやすさを改善する。

## 2. スコープ

### 今回含めるもの
- 範囲選択中/確定後に表示するテキストの配置を、重なりにくい位置へ自動調整する。
- 対象図形: 四角形/多角形/円形。
- 対象テキスト:
  - 点圧表示（クリック点、多角形各点）
  - 面積/有効測定範囲面積テキスト

### 今回含めないもの（将来対応）
- テキストフォント・色テーマの全面刷新
- 図形線の太さや描画アルゴリズム変更
- ユーザー手動でラベル位置を編集するUI

## 3. ユーザーストーリー

- ユーザーとして、図形線と文字が重ならず、点圧値や面積値を一目で読み取りたい。

## 4. 機能要件

### 4.1 配置ルール（共通）
- [ ] テキスト描画前に候補位置を複数評価し、図形と重なりが最小の位置を採用する。
- [ ] 最低限の候補順は「上→右→左→下」とする。
- [ ] どの候補も重なる場合は、図形外側へオフセットして配置する。
- [ ] キャンバス外にはみ出す場合は、表示領域内にクランプする。

### 4.2 四角形モード
- [ ] 面積テキストは矩形の外側優先で配置する。
- [ ] 点圧テキストはクリック点の近傍に出しつつ、矩形線との重なりを回避する。

### 4.3 多角形モード
- [ ] 各頂点の点圧テキストは頂点真上固定を基本としつつ、重なり時は右上/左上へ逃がす。
- [ ] 面積テキストは第1頂点基準表示を維持しつつ、ポリゴン本体との重なりを回避する。

### 4.4 円形モード
- [ ] 点圧テキストはクリック点上側優先で配置し、円周・ハンドルとの重なりを回避する。
- [ ] 面積テキストは円外側（上側）優先で配置し、円内部の視認性を優先する。

### 4.5 再配置タイミング
- [ ] ドラッグ移動・ハンドル編集・図形確定時にテキスト位置を再計算する。
- [ ] `point_pressure` / `text` の既存タグ運用は維持する。

## 5. 非機能要件

- 可読性: 図形線・頂点マーカーと文字が重ならないこと。
- 一貫性: 3モードで同じ重なり回避思想を適用すること。
- 安定性: 再描画時のちらつき・残像（古いテキスト残り）を発生させないこと。

## 6. 技術的考慮事項（参考）

> このセクションは壁打ち時点のメモです。詳細設計は `/add-feature` 実行時に `steering/design.md` として生成されます。

### 現状コード上の主対象
- `show_point_pressure_text(...)`
- `show_polygon_point_pressure_text(...)`
- `calculate_brightness2(...)` の `canvas.create_text(...)`
- `calculate_brightness3(...)` の表示テキスト更新
- `on_mouse_down` / `on_mouse_up` / `on_mouse_drag` 内の再描画処理

### 実装アプローチ（案）
- `compute_non_overlap_text_position(anchor, candidates, avoid_shapes, canvas_size)` の補助関数を追加。
- `canvas.bbox(text_id)` を使い、図形BBoxとの交差判定で候補評価する。
- 最小差分で既存呼び出し箇所から新配置関数を通す。

### 注意点
- 描画中（ドラッグ中）は高頻度再計算になるため、候補数を絞って負荷を抑える。
- 日本語文字幅を含む実BBoxはフォント依存のため、`canvas.bbox` 実測値を優先する。

## 7. 受け入れ条件

- [ ] 四角形/多角形/円形のいずれでも、図形線とテキストが重なって読めない状態が発生しない
- [ ] 点圧テキストと面積テキストがキャンバス外にはみ出さない
- [ ] 図形移動/編集時にテキスト位置が追従し、表示破綻しない
- [ ] 既存の圧力計算値・Excel出力値には影響を与えない
- [ ] 文字化けが発生しない
