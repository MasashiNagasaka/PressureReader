# スプラッシュ2 見栄え改善 仕様書

> 作成日: 2026-09-11
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- 現在のスプラッシュ2は案内文を表示できているが、画面としての質感が弱く見栄えが良くない。
- 起動直後にユーザーの視線を集め、必要情報を読みやすく伝えられる表示へ改善する。

---

## 2. スコープ

### 今回含めるもの
- スプラッシュ2の視覚デザイン改善
  - ウィンドウ配色
  - 文字サイズ・文字色
  - レイアウト（見出し + 本文）
- 既存メッセージ文言の可読性向上

### 今回含めないもの
- スプラッシュ1の画像変更
- メイン画面UI変更
- メッセージ文言そのものの意味変更

---

## 3. デザイン方針

- 方向性: 「業務ツールらしい落ち着き + 読みやすさ」
- 余白を十分に取り、視線誘導を明確化する。
- 文字色コントラストを強め、短時間表示でも内容が把握しやすい状態にする。

---

## 4. 機能要件（見た目）

### 4.1 ウィンドウ構成
- [ ] スプラッシュ2は「ヘッダー領域」と「本文領域」の2段構成にする。
- [ ] ヘッダーにタイトルを表示:
  - `ご案内`
- [ ] 本文は現行の3箇条をそのまま表示する。

### 4.2 配色（推奨）
- [ ] 背景色:
  - 全体: `#f4f7fb`（淡い青灰）
  - ヘッダー: `#1f3a5f`（濃紺）
- [ ] 文字色:
  - ヘッダータイトル: `#ffffff`
  - 本文: `#1f2d3d`
  - 箇条書き記号/強調: `#0f6ab4`

### 4.3 フォント・サイズ
- [ ] タイトル:
  - `("Meiryo ui", 16, "bold")`
- [ ] 本文:
  - `("Meiryo ui", 13)`（boldなし）
- [ ] 行間を確保し、1行ごとの読みやすさを優先する。

### 4.4 レイアウト
- [ ] ウィンドウサイズは現行よりやや横長にし、折り返しを最小化する。
  - 目安: 幅 860〜920、高さ 280〜320
- [ ] 左右余白は24px以上、上下余白は16px以上を確保する。
- [ ] 本文は左揃え、段落間に適度な余白を入れる。

### 4.5 表示時間（現仕様維持）
- [ ] スプラッシュ2の表示時間は8秒を維持する。

---

## 5. 技術的考慮事項（参考）

- Tkinterでの実装想定:
  - `Toplevel`（または専用 `Tk`）に `Frame` を2つ配置
  - ヘッダー `Frame` にタイトル `Label`
  - 本文 `Frame` に複数 `Label` を縦並び配置
- `messagebox.showinfo` はフォント・配色制御が難しいため使用しない。

---

## 6. 受け入れ条件

- [ ] 現在より見栄えが向上し、案内ウィンドウとして自然に見える
- [ ] タイトルと本文の視覚的階層が明確である
- [ ] 本文3箇条が8秒以内で読み取りやすい
- [ ] 文字化けが発生していない
- [ ] 既存の起動シーケンス（スプラッシュ1→スプラッシュ2→メイン）に回帰がない
