# スケーリング表示に単位（mm/px）を明示する仕様書

> 作成日: 2026-09-10
> ステータス: Draft
> 用途: `/add-feature` 向け実装仕様

---

## 1. 背景・目的
- 現在のスケーリング表示は設定値の単位が画面上で明示されていない。
- ユーザーが値の意味を即座に判別できるように、`mm/px` を表示したい。

---

## 2. スコープ

### 2.1 対象
- スケーリング行（`スケーリング` ボタン + 設定値表示欄）のUI表示

### 2.2 非対象
- スケーリング計算ロジック（換算式、丸め桁数）
- スケーリングボタン押下時のダイアログ挙動
- 他行（温度・湿度・明度・出力系）の配置変更

---

## 3. 仕様

### 3.1 表示形式
- スケーリング行は次の順で表示する。  
  `スケーリング` ボタン + 設定値欄 + `mm/px`

### 3.2 配置・サイズ
- `スケーリング` ボタンの位置は変更しない（現行 row/column を維持）。
- 設定値欄（`pixmm_entry`）の横幅を現行より狭める。
- 狭めた余白に `mm/px` ラベルを同一行に追加する。
- 既存の操作フロー（上から下）を崩さない。

### 3.3 挙動
- 設定値欄の表示・更新値は現行と同じ（数値のみ）。
- `mm/px` ラベルは常時表示とする。
- スケーリング未設定時でもラベルは表示してよい（設定値欄が空のまま）。

---

## 4. 受け入れ条件
- [ ] スケーリング行に `mm/px` が表示される
- [ ] `スケーリング` ボタンの位置が実装前と同じ
- [ ] 設定値欄の横幅が狭まり、レイアウト崩れがない
- [ ] 設定値の算出・表示更新ロジックに回帰がない

---

## 5. 影響範囲（想定）
- `src/PressureReader.py`
  - スケーリング行のウィジェット定義（`button_pixmm` / `pixmm_entry` 周辺）
  - `mm/px` 用ラベル追加

---

## 6. 実装メモ
- 既存の grid 配置を尊重し、最小変更で `mm/px` ラベルを追加する。
- 文字化け回避のため、UTF-8で編集・保存する。
