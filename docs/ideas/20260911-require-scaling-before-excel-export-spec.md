# Excel出力前スケーリング必須化 仕様書

> 作成日: 2026-09-11
> ステータス: Draft
> 用途: `/add-feature` 実装用

---

## 1. 背景・目的
- 現状はスケーリング（`pixmm_entry`）未設定でも `選択範囲Excel出力` が実行できる。
- その結果、セル寸法の意味づけがないまま出力され、誤解を招く可能性がある。
- ユーザーに「スケーリング設定なしでExcel出力を進めない」ことを明確に伝えるため、ボタン押下時メッセージで設定を促す。

---

## 2. スコープ

### 2.1 対象
- `選択範囲Excel出力` ボタン（`button_xl`）押下時のガード表示
- `save_brightness_to_xlsx()` 実行前の入力ガード

### 2.2 非対象
- Excel出力データの計算ロジック
- スケーリングダイアログのUI・入力方式
- ファイル名フォーマット（`1cell：...`）の仕様変更

---

## 3. 仕様

### 3.1 ボタン押下時メッセージ（主制御）
- `pixmm_entry` が未設定（空欄、数値変換不可、0以下）の状態で `選択範囲Excel出力` ボタンを押した場合、出力処理を実行せずメッセージを表示する。
- メッセージ文言は、スケーリング設定を促す明確な内容にする。
  - 例: `スケーリングを設定してください`

### 3.2 ガード処理（副制御）
- `save_brightness_to_xlsx()` の先頭で、`pixmm_entry` の妥当性を再チェックする。
- 未設定/不正値の場合は処理を中断し、ユーザーへ案内メッセージを表示する。
  - 例: `スケーリングを設定してください`

### 3.3 既存動作維持
- 画像未読込・選択範囲未設定の既存ガード（`no_image` / `no_rect`）は維持する。
- スケーリング設定済み時のExcel出力処理は従来どおりとする。

---

## 4. 技術的考慮事項（参考）
> 詳細設計は `/add-feature` 実行時に確定。

- 既存では `save_brightness_to_xlsx()` 内で `pixmm_entry` 空欄時に `conversion_factor = 0` を許容しているため、ここを必須化へ変更する。
- ボタン状態（有効/無効）は変更せず、押下時ガードのみで制御する。

---

## 5. 受け入れ基準
- [ ] スケーリング未設定/不正値で `選択範囲Excel出力` ボタン押下時、メッセージ表示して出力中断する
- [ ] スケーリングに有効な正の数値を設定した状態では、従来どおりExcel出力できる
- [ ] 既存の出力ロジックと他機能に回帰がない
- [ ] 文字化けが発生していない
