# 検出値表示欄の縦間隔調整（温度/湿度欄準拠）仕様書

> 作成日: 2026-09-11
> ステータス: Draft
> 用途: `/add-feature` 実装用

---

## 1. 背景・目的
- `検出値（平均）` / `検出値（最大）` / `検出値（最小）` の値表示欄が、縦方向にくっついて見える。
- 同画面の `温度[℃]` / `湿度[%]` の値表示欄はくっついて見えないため、この見え方を基準に検出値欄も調整する。

---

## 2. スコープ

### 2.1 対象
- 右パネルの検出値表示エリア（`detected_value_frame`）内の3つの値表示欄
  - `atai_ave_entry`
  - `atai_max_entry`
  - `atai_min_entry`
- 同行の `MPa` ラベルの縦位置調整（必要最小限）

### 2.2 非対象
- 検出値の計算ロジック（平均/最大/最小）
- ラベル文言、ラベル文字サイズ、ラベルの横位置
- 右端余白・枠線設定の方針

---

## 3. 仕様

### 3.1 温度/湿度欄を基準にした縦間隔
- 検出値3行の値表示欄が、縦方向に視覚的に分離して見えるようにする。
- 見え方の基準は `温度[℃]` / `湿度[%]` の値表示欄とし、同程度の分離感を目標とする。

### 3.2 実装方針（レイアウト）
- `detected_value_frame` 内の各行に、縦方向の `pady` を付与して間隔を確保する。
- 過度な空きを作らず、既存の上下フローを崩さない最小調整とする。
- 3行のうち先頭行のみ上余白を持たせるなど、温度/湿度欄と同様のリズムで調整する。

### 3.3 動作維持
- 値更新（数値表示 / `測定範囲外`）動作は変更しない。
- 画面リセット、選択範囲クリア、画像読み込み時のクリア動作に回帰を出さない。

---

## 4. 技術的考慮事項（参考）
> 詳細設計は `/add-feature` 実行時に確定。

- 対象箇所は `src/PressureReader.py` の `detected_value_frame` 周辺。
- 現状は各行の `pady=(0,0)` が中心で、行間が詰まって見える。
- 温度/湿度欄（`ondo_entry` / `shitsudo_entry`）の `grid(... pady=...)` を参照し、同系統の余白調整を適用する。
- 変更は検出値表示エリア限定で行い、他のUI入力欄には影響させない。

---

## 5. 受け入れ基準
- [ ] `検出値（平均）` / `検出値（最大）` / `検出値（最小）` の値表示欄が、縦方向にくっついて見えない
- [ ] 見え方が `温度[℃]` / `湿度[%]` 欄と同程度の分離感になっている
- [ ] ラベル文言・ラベル文字サイズ・横方向レイアウトに変更がない
- [ ] 検出値の表示内容（数値 / `測定範囲外`）に回帰がない
- [ ] 文字化けが発生していない
