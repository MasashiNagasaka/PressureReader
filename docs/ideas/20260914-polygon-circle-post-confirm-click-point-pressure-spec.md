# 多角形/円形モードの確定後クリック点圧表示 仕様書

> 作成日: 2026-09-14
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- 範囲選択の操作方針として、確定後は通常クリックで新規選択を開始しない仕様に統一したい。
- その一方で、確定後でもクリックした座標の点圧力（MPa）は参照したい。
- 誤操作を防ぎつつ、現場での即時確認性を維持するため、確定後クリックでは「形状は維持、点圧のみ更新」を実現する。

---

## 2. スコープ

### 今回含めるもの
- 多角形モードで、確定後の通常クリックでは新規開始せず、クリック点の点圧を表示する。
- 円形モードで、確定後の通常クリックでは新規開始せず、クリック点の点圧を表示する。
- 既存の点圧表示形式（`xx.xxxMPa` / `測定範囲外`、点の上側表示）を踏襲する。
- ドラッグ操作（多角形頂点移動/全体移動、円形移動/ハンドルリサイズ）は既存どおり維持する。

### 今回含めないもの（将来対応）
- 四角形モードの仕様変更
- 圧力換算ロジック（`c2p`）の変更
- 検出値欄（平均/最大/最小）の表示仕様変更

---

## 3. ユーザーストーリー

- 解析担当者として、確定済みの多角形/円形を壊さずに、画像上の任意点の圧力を確認したい。
- 解析担当者として、ドラッグ編集（頂点移動・円移動・リサイズ）は従来どおり使いたい。

---

## 4. 機能要件

### 4.1 共通: 確定後クリックの基本挙動
- [ ] 多角形/円形の選択範囲確定後、通常クリックで新規選択開始しない。
- [ ] 確定後クリック時は、既存の選択範囲・検出マーク・範囲統計（平均/最大/最小）を維持する。
- [ ] 確定後クリック時に、クリック座標の点圧表示のみ更新する。
- [ ] 優先順位は「通常クリック（ドラッグなし）= 点圧表示優先」「ドラッグ発生 = 移動/形状変更優先」とする。

### 4.2 多角形モード
- [ ] `polygon_id` が存在する確定状態でクリックした場合、新規頂点は追加しない。
- [ ] 確定状態クリック時、クリック点の上側に点圧を1件表示する（確定前の各頂点ラベルとは別扱い）。
- [ ] 多角形の頂点ドラッグ/全体ドラッグの既存挙動を維持する。
- [ ] 多角形の確定状態でクリック後にドラッグが発生した場合は、点圧表示より編集操作（頂点移動/全体移動）を優先する。

### 4.3 円形モード
- [ ] `circle_id` が存在する確定状態でクリックした場合、新規円は作成しない。
- [ ] 確定状態クリック時、クリック点の上側に点圧を1件表示する。
- [ ] 円内部ドラッグ移動、ハンドルドラッグリサイズの既存挙動を維持する。
- [ ] 「通常クリック」はドラッグを伴わないクリックとし、ドラッグ開始時は点圧表示より編集操作を優先する。

### 4.4 点圧表示仕様
- [ ] 表示文言は既存仕様を踏襲し、`点圧` 固定語は表示しない。
- [ ] 表示内容は `xx.xxxMPa`、有効範囲外は `測定範囲外` とする。
- [ ] 表示位置はクリック点の上側（既存単点表示と同じアンカー）とする。
- [ ] 次回クリック時は前回の確定後クリック点圧表示を置換する。

---

## 5. 非機能要件

- パフォーマンス: クリック時の点圧表示は体感遅延なく更新されること。
- 信頼性: 画像未読込/解析条件未設定時の既存ガードを維持し、例外を発生させないこと。
- 操作一貫性: 多角形/円形で「確定後は新規開始しない」方針を維持すること。

---

## 6. 技術的考慮事項（参考）

> このセクションは壁打ち時点のメモです。詳細設計は `/add-feature` 実行時に `steering/design.md` として生成されます。

### 実装アプローチ（案）
- `on_mouse_down` の `mode == "polygon"` 分岐で、`polygon_id` が存在する場合は `return` 前に点圧表示処理を呼ぶ。
- `on_mouse_down` の `mode == "circle"` 分岐で、`circle_id` 存在時の各分岐（内部/ハンドル/外側）において、通常クリック時の点圧表示導線を追加する。
- ドラッグ開始判定との競合を避けるため、必要に応じて `on_mouse_up` 側で「移動量しきい値（クリック判定）」を使う。

### 既存コードへの影響（想定）
- 変更: `src/PressureReader.py` — `on_mouse_down`, `on_mouse_up`（必要時）, 点圧表示タグ管理
- 再利用: `calculate_point_pressure`, `show_point_pressure_text`, `show_polygon_point_pressure_text`

### 注意点・リスク
- 円形モードは「クリック」と「移動開始」が同じ入口のため、ドラッグ判定設計を誤ると既存編集操作に回帰が出る。
- 多角形モードの確定前頂点ラベルと、確定後クリック点圧ラベルのタグ競合に注意する。

## 7. 受け入れ条件

- [ ] 多角形モードで範囲確定後、クリックしても新規頂点は追加されない。
- [ ] 多角形モードで範囲確定後、クリック点の点圧が画像上に表示される。
- [ ] 多角形モードで範囲確定後、ドラッグ時は点圧表示より頂点移動/全体移動が優先される。
- [ ] 円形モードで範囲確定後、クリックしても新規円は作成されない。
- [ ] 円形モードで範囲確定後、クリック点の点圧が画像上に表示される。
- [ ] 円形の内部ドラッグ移動とハンドルリサイズが従来どおり動作する。
- [ ] 円形モードで範囲確定後、ドラッグ時は点圧表示より移動/リサイズが優先される。
- [ ] 既存の四角形モード、範囲統計表示、高圧検出マークに回帰がない。
- [ ] 文字化けが発生していない。
