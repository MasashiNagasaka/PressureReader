# 標準色見本: 最明度キーのみ面積条件を緩和する 仕様書

> 作成日: 2026-09-15
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景

標準色見本処理で、最も明るいキー（例: `0.1`）が「白に近い薄ピンク」のため、  
連結成分の面積しきい値（`min_region_size = ROIの7%`）で落ち、読取失敗しやすい。

---

## 2. 目的

- 最明度キーのみ取りこぼしを減らす。
- 他の明度キーや他機能への影響は最小化する。

---

## 3. 要件

1. 対象は標準色見本処理（`value_key=="14"`）のみ。
2. 面積条件の緩和は「一番明るい明度キー」に対応する領域のみ。
3. 一番明るいキー以外の判定条件は現状維持。
4. 点圧算出、可視化、Excel出力など他処理には影響させない。

---

## 4. 仕様詳細

### 4.1 現行

- 連結成分の採用条件:
  - `region_size >= total_pixels * 0.07`

### 4.2 変更

- 連結成分の候補を平均明度で昇順（暗→明）に並べる。
- そのうち **最も明るい1成分のみ** 面積条件を緩和する。
  - 通常成分: `region_size >= total_pixels * 0.07`（据え置き）
  - 最明度成分: `region_size >= total_pixels * 0.02`（緩和）

> 備考: 値は初期案。必要なら 0.02〜0.03 の範囲で調整可。

### 4.3 判定範囲

- 変更範囲は `PressureReader.py` の標準色見本採色ブロック内に限定する。
- `value_key=="14"` 以外のモードには適用しない。

---

## 5. 受け入れ条件

- [ ] 最明度キー（例: 0.1）の読取失敗率が低下する。
- [ ] それ以外のキーの並び・値の安定性に大きな悪化がない。
- [ ] 標準色見本以外の機能に回帰がない。

---

## 6. 実装メモ

- ラベリング後、各成分の `mean_final` を計算した上で:
  - 最明度成分（`mean_final` 最大）を特定
  - 当該成分にのみ緩和しきい値を適用
- ログに以下を追加:
  - 最明度成分の `region_size` と適用しきい値
  - 採用/棄却結果
