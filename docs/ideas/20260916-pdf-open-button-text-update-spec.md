# PDF変換ボタン文言更新 仕様書

> 作成日: 2026-09-16
> ステータス: Draft
> 想定コマンド: `/add-feature`

---

## 1. 背景

現行の `PDF⇒PNG変換` ボタンは、実際には PNG 変換だけでなく、変換後の PNG を開く処理まで行っている。  
ボタン文言と実処理の意味を一致させ、ユーザーの操作理解を改善する。

---

## 2. 変更方針

### 2.1 ボタン文言

- 変更前: `PDF⇒PNG変換`
- 変更後: `PDF→PNG変換して開く`

### 2.2 未設定状態メッセージ（画像未読込ガイダンス）

- 対象: 画像未表示時にクリックした際の案内文
- 変更前: `『PDF⇒PNG変換』ボタン、もしくは『PNGを開く』ボタンを押してください`
- 変更後: `『PDF→PNG変換して開く』ボタン、もしくは『PNGを開く』ボタンを押してください`

### 2.3 ボタンサイズ（レイアウト）調整

- 文言変更でボタン表示幅が増えるため、右ペイン上部のボタン幅（padding）を再調整する。
- `PDF→PNG変換して開く` と `PNGを開く` の左端位置・縦並びバランスを維持する。
- ボタンテキストの欠け、折返し、右端はみ出しが発生しないこと。

---

## 3. 非対象

- PDF→PNG の変換処理ロジックそのもの
- PNGを開くボタンの機能
- 他メッセージ文言（本仕様で明示した対象以外）

---

## 4. 受け入れ条件

- [ ] 右ペインのボタン表示が `PDF→PNG変換して開く` になっている
- [ ] 画像未表示時のガイダンス文言が新しいボタン名に一致している
- [ ] `PDF→PNG変換して開く` ボタンの文字欠け・折返し・はみ出しがない
- [ ] `PNGを開く` ボタンとの配置バランス（左端位置と縦間隔）が崩れていない
- [ ] 既存の PDF 変換→自動表示フローに回帰がない
