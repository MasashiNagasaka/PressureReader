# 「圧力最大点」ラベルの用語改善仕様書

> 作成日: 2026-09-10
> ステータス: Draft
> 用途: `/add-feature` 実装用

---

## 1. 背景・目的
- 現在のUIラベル `圧力最大点` は意味が抽象的で、初見ユーザーに操作意図が伝わりにくい。
- 実際の機能は「選択範囲内で圧力が高い点（= 低明度点）を、指定件数だけ青丸で表示する」機能である。
- ラベル文言または補足説明を改善し、ユーザーが迷わず使える状態にする。

---

## 2. スコープ

### 2.1 対象
- 右パネルの `圧力最大点：` ラベル（スライダー見出し）
- 必要に応じて、同エリアの補足説明テキスト

### 2.2 非対象
- スライダーの計算ロジック
- マーキング描画ロジック（青丸表示）
- スライダー値の上限下限（0〜100）

---

## 3. 仕様

### 3.1 文言改善（必須）
- `圧力最大点：` を、以下の文言に変更する。

指定文言:
- `選択範囲の高圧検出箇所：`

### 3.2 表示ルール
- スライダー見出しラベルは `選択範囲の高圧検出箇所：` とする。
- 表示順は以下の順にする:
  1. `選択範囲の高圧検出箇所：`
  2. `表示数の設定`
  3. 現在値 + スライダー
- `表示数の設定` はスライダーの上段（または直前行）に置き、スライダー右横には置かない。
- スライダー左側の表示は固定文字列 `0～100` ではなく、スライダーの現在値（数値）を表示する。
- 現在値表示はスライダー操作に連動して更新する。

### 3.3 レイアウト方針
- 既存のスライダー位置・行構成は維持する（レイアウト破壊を避ける）。
- `表示数の設定` は説明ラベルとして扱い、操作フローを崩さない最小変更で実装する。
- スライダー右横スペースが空くため、スライダー長は元の大きさに戻す。

---

## 4. 受け入れ基準
- [ ] `圧力最大点` が `選択範囲の高圧検出箇所：` へ置換されている
- [ ] `表示数の設定` がスライダーの上段（または直前行）に表示されている
- [ ] スライダー長が実装前の大きさに戻っている
- [ ] スライダー左側に現在値が表示され、操作に連動して更新される
- [ ] スライダー操作時の動作（青丸マーキング数の変化）が従来どおり
- [ ] 既存の他UIレイアウトに崩れがない
- [ ] 表示文言が日本語として自然で、意味が一意に理解できる
