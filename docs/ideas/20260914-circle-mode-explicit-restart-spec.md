# 円形モードの新規開始を明示操作限定にする仕様書

> 作成日: 2026-09-14
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- 現在の円形モードは、円形選択を確定した後でも、選択範囲外クリックで新しい円形作成が始まる。
- 多角形モードは確定後クリックで新規開始せず、既存形状の編集（頂点移動/全体移動）を優先するため、操作方針に差がある。
- 円形モードを多角形モード寄りに統一し、確定後は通常クリックで新規開始しないようにして誤操作を防ぐ。

---

## 2. スコープ

### 今回含めるもの
- 円形モードで「確定後の通常クリックによる新規開始」を無効化
- 確定後は既存円の移動・リサイズ操作を維持
- 新規開始は明示操作経由に限定

### 今回含めないもの
- 多角形モード/四角形モードの仕様変更
- 点圧表示ロジックの仕様変更
- 圧力算出ロジック（`c2p`）の変更

---

## 3. 現状整理（コード調査）

- `on_mouse_down` の円形分岐では、`circle_id` がある場合:
  - 円内部クリック: `moving_circle=True` で移動開始
  - ハンドルクリック: `dragging_handle` でリサイズ開始
  - 上記以外（外側クリック）: 現在は新規円作成へ進む
- この「外側クリックで新規円作成」が、多角形モードの確定後クリック抑止と不一致になっている。

---

## 4. 機能要件

### 4.1 確定後の通常クリック挙動
- [ ] 円形が確定している状態（`circle_id` が有効）では、選択範囲外の通常クリックで新規円作成を開始しない。
- [ ] 外側クリック時は既存状態を維持し、円形選択・検出値・マーク表示を変化させない。

### 4.2 既存編集操作の維持
- [ ] 円内部クリック→ドラッグで既存円の移動は従来どおり可能とする。
- [ ] ハンドルクリック→ドラッグでリサイズは従来どおり可能とする。
- [ ] 円形確定（マウスアップ/右クリック）後の統計表示更新は従来挙動を維持する。

### 4.3 明示操作でのみ新規開始
- [ ] 新規円形の開始は次の明示操作時のみ許可する。
  - `選択範囲クリア` ボタン
  - モード切替（他モードへ変更後、円形モードへ戻す）
  - `画面リセット`

---

## 5. 技術的考慮事項（参考）

- 主変更箇所:
  - `on_mouse_down`（円形モード分岐）
- 実装方針:
  - `circle_id` が存在し、かつ「内部クリック」「ハンドルクリック」に該当しない場合は `return` して新規作成に進まない。
  - `circle_id` が存在しない場合のみ新規円作成フローに進む。
- 影響確認対象:
  - `on_mouse_drag`, `on_mouse_up`, `right_click`
  - `clear_selectarea`, `set_mode_circle`, `reset_to_startup_state`

---

## 6. 受け入れ条件

- [ ] 円形確定後、選択範囲外クリックでは何も起こらず、新規円は生成されない。
- [ ] 円内部ドラッグで移動できる。
- [ ] ハンドルドラッグでリサイズできる。
- [ ] `選択範囲クリア` 後は新規円の作成が可能になる。
- [ ] 他モードへ切替後に円形へ戻すと新規円の作成が可能になる。
- [ ] `画面リセット` 後は新規円の作成が可能になる。
- [ ] 既存の四角形/多角形モードに回帰がない。
- [ ] 文字化けが発生していない。
