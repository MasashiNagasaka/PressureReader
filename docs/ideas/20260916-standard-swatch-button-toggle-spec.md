# 標準色見本処理ボタン トグル化 仕様書

> 作成日: 2026-09-16
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

現状の `標準色見本処理` ボタンは押下後に一時的な矩形選択モードへ入るが、見た目上は通常のワンショットボタンで、現在状態（待機中/選択中）が分かりにくい。  
トグル化により、ユーザーが「今は色見本選択モードかどうか」を明確に判断できるようにする。

## 2. スコープ

### 今回含めるもの
- `標準色見本処理` ボタンを ON/OFF 状態を持つトグル挙動に変更する。
- ON時の見た目、OFF時の見た目を明確に分ける。
- 色見本矩形の確定後は自動的に OFF へ戻す。

### 今回含めないもの（将来対応）
- 色見本抽出ロジック（明度算出アルゴリズム）の変更
- 他ボタンのトグル化
- 右ペイン全体のレイアウト変更

## 3. ユーザーストーリー

- ユーザーとして、色見本選択モードが有効かどうかをボタン状態で判断したい。
- ユーザーとして、選択完了後に通常モードへ戻ったことを明確に認識したい。

## 4. 機能要件

### 4.1 トグル状態
- [ ] 初期状態は OFF とする。
- [ ] OFFでボタン押下時:
  - 色見本選択モードを ON にする。
  - 内部モードを `set_mode_rect("14")` 相当へ遷移する。
  - ボタン表示を ON 見た目に更新する。
- [ ] ONでボタン押下時:
  - 色見本選択モードを OFF にする（キャンセル）。
  - 内部モードを通常矩形 `set_mode_rect("99")` へ戻す。
  - ボタン表示を OFF 見た目に更新する。

### 4.2 自動OFF
- [ ] 色見本矩形の選択確定（マウスアップで `current_value != "99"` の分岐完了）後は、自動で OFF に戻す。
- [ ] 自動OFF時にボタン見た目も必ず OFF に戻る。

### 4.3 既存動作維持
- [ ] 色見本抽出結果の各明度欄反映・状態表示（未設定/設定完了/読取失敗）は現状維持。
- [ ] 通常解析モード（`current_value == "99"`）への復帰タイミングは現状互換とする。
- [ ] 感圧紙未選択時の表示制御（ボタン表示/非表示）は現状維持。

## 5. 非機能要件

- 可視性: ON/OFFが視覚的に判別できること。
- 保守性: 既存の `set_mode_rect("14")` / `set_mode_rect("99")` を活かして最小差分で実装すること。
- 安定性: 既存の矩形・多角形・円形モードの回帰を起こさないこと。

## 6. 技術的考慮事項（参考）

> このセクションは壁打ち時点のメモです。詳細設計は `/add-feature` 実行時に `steering/design.md` として生成されます。

### 実装アプローチ（案）
- `swatch_toggle_on = tk.BooleanVar(value=False)` を導入。
- ボタンコマンドを `toggle_swatch_mode()` に変更し、ON/OFFで `set_mode_rect("14")` / `set_mode_rect("99")` を切り替える。
- 既存の `on_mouse_up` 内 `if current_value != "99": set_mode_rect("99")` の箇所で、トグル状態も OFF に同期する。
- `button_iromihon.config(...)` でテキストまたは画像を ON/OFF 反映（既存 `icon13/icon14` を再利用）。

### 影響ファイル（想定）
- `src/PressureReader.py`

### 注意点・リスク
- ON時ホバー画像と状態ON画像の優先順を整理しないと、見た目がチラつく可能性がある。
- OFF復帰漏れがあると、意図しない色見本モード継続になるため、状態同期ポイントを明確化する。

## 7. 受け入れ条件

- [ ] 初期表示で `標準色見本処理` は OFF 状態である
- [ ] ボタン1回押下で ON になり、再押下で OFF になる
- [ ] ON中に色見本矩形を確定すると、自動で OFF + 通常矩形モードに戻る
- [ ] 色見本読取結果の反映、解析条件入力、通常点圧表示の既存挙動に回帰がない
- [ ] 文字化けが発生しない
