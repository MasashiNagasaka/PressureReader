# 初期状態ガイダンス文言修正 仕様書

> 作成日: 2026-09-11
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- 現在、画像未表示状態でキャンバス操作すると、
  `『PNGを開く』ボタンから、画像ファイルを選択してください`
  と表示される。
- 実際の導線は `PDF⇒PNG変換` も有効であり、現文言は不正確。
- 初期状態の案内を正しい操作手順に合わせる。

---

## 2. スコープ

### 今回含めるもの
- 画像未表示時ガードメッセージの文言変更。

### 今回含めないもの
- ボタン配置変更
- 画像読み込みロジック変更
- PDF変換ロジック変更

---

## 3. 機能要件

### 3.1 文言変更
- [ ] 画像未表示時のガイダンス文言を以下へ変更する:
  - `『PDF⇒PNG変換』ボタン、もしくは『PNGを開く』ボタンを押してください`

### 3.2 表示方式
- [ ] 既存の中央オーバーレイ表示（2秒表示）を維持する。
- [ ] 他のガードメッセージ（選択範囲未作成、解析条件不足など）への影響を出さない。

---

## 4. 技術的考慮事項（参考）

- 想定変更箇所:
  - `src/PressureReader.py` の画像未表示判定関数（`no_image`）内メッセージ文字列
- 文字列置換のみの最小変更とする。

---

## 5. 受け入れ条件

- [ ] 画像未表示状態でキャンバスを操作した際、次の文言が表示される:
  - `『PDF⇒PNG変換』ボタン、もしくは『PNGを開く』ボタンを押してください`
- [ ] 表示時間・表示位置は従来どおり
- [ ] 既存の他ガードメッセージに回帰がない
- [ ] 文字化けが発生していない
