# 標準色見本処理後の自動クリア復帰 仕様書

> 作成日: 2026-09-09
> ステータス: Draft
> 用途: `/add-feature` 実装入力

---

## 1. 背景・目的

`標準色見本処理` ボタン後の矩形選択完了時に、
`四角形モード` クリック相当（`button_Region_mode.invoke()`）で通常モード復帰を試みても、
実動作では復帰しないケースが残る。

一方、同じ状況で `選択範囲クリア` ボタンを押すと通常モードへ復帰できることを確認した。

目的は、**標準色見本処理の矩形選択完了直後に、内部的に `選択範囲クリア` を実行し、通常モード復帰を安定化**すること。

---

## 2. スコープ

### 2.1 実施すること
- 標準色見本処理（`current_value == "14"`）の矩形選択完了時に `clear_selectarea()` を呼び出す。
- 復帰後のモード状態を通常四角形モード（`99`）へ統一する。

### 2.2 実施しないこと
- 標準色見本採色アルゴリズムの変更。
- 多角形/円モードの操作仕様変更。
- 圧力換算ロジック変更。

---

## 3. 現状整理

- 現在の `on_mouse_up` では、標準色見本処理後に `button_Region_mode.invoke()` を試している。
- この方法は環境依存で復帰しないケースがある（ユーザー実測）。
- `clear_selectarea()` は以下を一括実施するため復帰が安定している:
  - 描画オブジェクト削除（`rect/text/line/mark/polygon/circle`）
  - 選択状態変数の初期化
  - `mode == "rect"` の場合に `modevar.set(1)` + `set_mode_rect("99")`

---

## 4. 仕様

### 4.1 復帰トリガー
- [ ] `on_mouse_up` の矩形選択完了時、`current_value == "14"` なら `clear_selectarea()` を実行する。

### 4.2 復帰方法
- [ ] 復帰手段は `四角形モード` 擬似クリックではなく、`clear_selectarea()` を第一手段とする。
- [ ] これにより選択範囲描画を消去しつつ、通常矩形モードへ戻す。

### 4.3 復帰後の期待状態
- [ ] `mode == "rect"`
- [ ] `current_value == "99"`
- [ ] `modevar == 1`（四角形モード）
- [ ] `atai_ave_entry` はクリアされている（`clear_selectarea` 既存仕様）
- [ ] 直後に通常の選択範囲作成が可能

---

## 5. 受け入れ条件

- [ ] `標準色見本処理` → 矩形選択 → マウスアップで、手動操作なしに通常モードへ戻る。
- [ ] 復帰時に選択範囲表示はクリアされる。
- [ ] `四角形モード` ボタンを追加で押す必要がない。
- [ ] 既存の `選択範囲クリア` ボタン手動操作と挙動差異がない。
- [ ] 多角形/円モードに回帰影響がない。

---

## 6. 実装メモ（/add-feature 引き継ぎ）

### 6.1 変更対象（想定）
- `src/PressureReader.py`

### 6.2 変更ポイント（想定）
- `on_mouse_up` の `current_value == "14"` 分岐
- 既存の `button_Region_mode.invoke()` 経路は撤去またはフォールバック化

### 6.3 注意点
- `clear_selectarea()` は平均圧表示もクリアするため、仕様として明示した上で実装する。
- 標準色見本以外の矩形解析（`current_value == "99"`）には適用しない。

---

## 7. テスト観点

- 標準ケース: 標準色見本処理1回で通常復帰する。
- 連続ケース: 標準色見本処理を連続実行しても毎回復帰する。
- 視覚確認: 復帰直後に前回選択矩形が残らない。
- 回帰確認: 通常四角形解析時は従来どおり選択保持/表示される。
