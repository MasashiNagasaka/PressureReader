# Excel出力 成功/失敗メッセージ表示 仕様書

> 作成日: 2026-09-11
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- 現在のExcel出力は保存処理完了後のユーザー通知がなく、成功したか判断しづらい。
- また、保存失敗時のユーザー通知仕様も明確でない。
- 成功時/失敗時のメッセージを明示し、ユーザーが次の操作を判断しやすくする。

---

## 2. スコープ

### 今回含めるもの
- `選択範囲Excel出力` の保存成功時メッセージ表示
- `選択範囲Excel出力` の保存失敗時メッセージ表示

### 今回含めないもの
- Excelファイル内容や保存形式の変更
- エラー時メッセージ仕様の全面見直し

---

## 3. 機能要件

### 3.1 成功時メッセージ
- [ ] Excel保存成功後に、次の文言を表示する:
  - `Excelファイルを出力しました`

### 3.2 失敗時メッセージ
- [ ] Excel保存失敗時に、次の文言を表示する:
  - `Excelファイルの出力に失敗しました`

### 3.3 表示タイミング
- [ ] `wb.save(file_path)` が正常終了したときのみ表示する。
- [ ] `wb.save(file_path)` で例外が発生した場合に失敗メッセージを表示する。
- [ ] 保存ダイアログを `CANCEL` した場合は成功/失敗いずれのメッセージも表示しない。

### 3.4 表示方式
- [ ] 既存のオーバーレイ通知方式（中央表示ラベル + 数秒後自動消去）に合わせる。
- [ ] 既存メッセージとの見た目整合を保つ。

---

## 4. 技術的考慮事項（参考）

- 実装箇所:
  - `src/PressureReader.py` の `save_brightness_to_xlsx()`
- 既存のメッセージ表示パターン（`tk.Label(...); root.after(..., destroy)`）を再利用する。
- 保存処理は `try/except` で失敗を捕捉し、失敗メッセージを表示したうえで処理継続する。

---

## 5. 受け入れ条件

- [ ] 保存成功時のみ `Excelファイルを出力しました` が表示される。
- [ ] 保存失敗時のみ `Excelファイルの出力に失敗しました` が表示される。
- [ ] 保存キャンセル時はメッセージが表示されない。
- [ ] 既存のExcel出力動作（保存内容・ファイル名生成）に回帰がない。
- [ ] 文字化けが発生していない。
