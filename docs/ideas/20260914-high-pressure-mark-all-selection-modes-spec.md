# 高圧検出箇所マーク処理: 全選択モード対応 仕様書

> 作成日: 2026-09-14
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- 現在の高圧検出箇所マーク処理は、実質的に四角形選択前提である。
- 多角形/円形では選択範囲内への限定ができず、意図しない位置にマークが出る場合がある。
- ユーザー操作に合わせて、未選択時は画像全体、選択済み時は各モードの選択範囲内のみを対象にしたい。

---

## 2. スコープ

### 今回含めるもの
- 高圧検出箇所マーク処理の対象領域をモード別に最適化
- 四角形/多角形/円形の3モード対応
- 未選択時の画像全体対象ルールの明確化

### 今回含めないもの
- 圧力換算ロジック（`c2p`）の変更
- スライダーUI（位置・見た目・値範囲）の変更
- Excel出力仕様の変更

---

## 3. 機能要件

### 3.1 対象領域ルール
- [ ] 選択範囲が何もない場合は、画像全体を対象に高圧検出マークを付与する。
- [ ] 選択範囲がある場合は、現在モードに応じた選択範囲内だけを対象にする。

### 3.2 モード別対応
- [ ] 四角形モード: 既存の矩形範囲内のみ対象
- [ ] 多角形モード: ポリゴンマスク内のみ対象
- [ ] 円形モード: 楕円マスク内のみ対象

### 3.3 スライダー連動
- [ ] `表示数の設定` スライダー変更時、現在の対象領域ルールに従って再描画する。
- [ ] マークは既存どおり最大N件（スライダー値）を表示する。

### 3.4 既存挙動維持
- [ ] 画像未読込時のガード挙動は維持する。
- [ ] 選択範囲の作成/移動/確定操作と競合しない。

---

## 4. 技術的考慮事項（参考）

- 対象関数:
  - `update_label()`
  - `mark_lowest_brightness_points(...)`
- 実装方針:
  - モード判定（`rect/polygon/circle`）を導入
  - 各モードで `mask_full`（元画像サイズ）を生成し、`filtered_image` に適用
  - マーク表示座標は既存の `scale + offset` 変換を再利用
- 未選択判定:
  - 四角形: `rect is None`
  - 多角形: `polygon_id is None` または頂点不足
  - 円形: `circle_id is None` または半径ゼロ

---

## 5. 受け入れ条件

- [ ] 未選択時は画像全体に対して高圧検出箇所が表示される。
- [ ] 四角形選択時は矩形内のみ表示される。
- [ ] 多角形選択時は多角形内のみ表示される。
- [ ] 円形選択時は円形内のみ表示される。
- [ ] 文字化けが発生していない。
