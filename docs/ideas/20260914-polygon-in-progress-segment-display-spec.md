# 多角形選択の途中線表示（確定点どうし）仕様書

> 作成日: 2026-09-14
> ステータス: Draft
> 用途: /add-feature への入力

---

## 1. 背景・目的

- 現在の多角形モードは、全頂点を選択して右クリック確定するまで、点どうしを結ぶ線が表示されない。
- そのため、頂点追加の途中で形状を視覚確認しづらく、誤クリックや再選択が起きやすい。
- 頂点追加の途中状態でも、確定済み頂点どうしを線で結んで表示し、操作中の見通しを改善する。

---

## 2. スコープ

### 今回含めるもの
- 多角形モードでの途中状態における折れ線表示
- 表示対象は「確定済みの点どうし」のみ
- 既存の右クリック確定で最終多角形を作る挙動は維持

### 今回含めないもの
- カーソル追従の仮線表示（最後の点からマウス位置への線）
- 右クリック確定ロジックの変更
- 点圧表示の仕様変更（別タスクで完了済み）

---

## 3. 現状整理（コード調査）

- 関連処理:
  - `on_mouse_down`（多角形点追加）
  - `on_mouse_drag`（確定後の頂点移動/多角形移動）
  - `right_click`（多角形確定で `create_polygon`）
- 現状は `polygon_id` が `None` の間、線描画が行われないため途中形状が見えない。
- `polygon_id` は右クリック確定時に初めて `canvas.create_polygon(...)` で作成される。

---

## 4. 機能要件

### 4.1 途中線表示
- [ ] 多角形モードで2点目以降を追加した時点で、確定済み頂点どうしを順に結ぶ線を表示する。
- [ ] 途中状態の線は閉じない（最後の点から最初の点への線は引かない）。
- [ ] 線の見た目は既存多角形の枠線と整合する（色・太さは既存準拠）。

### 4.2 更新タイミング
- [ ] 頂点追加時に途中線を再描画する。
- [ ] 頂点移動時も途中線/確定後線が整合するよう再描画する。
- [ ] 範囲クリア、モード切替、画面リセット時に途中線表示をクリアする。

### 4.3 確定挙動との整合
- [ ] 右クリック確定時は既存どおり多角形（閉じた枠線）へ遷移する。
- [ ] 確定後は既存の範囲統計計算・高圧検出マーク処理に回帰がない。

---

## 5. 技術的考慮事項（参考）

- 実装方針案:
  - 多角形途中表示専用タグ（例: `polygon_preview`）を導入して描画管理を分離する。
  - 点追加時:
    - `len(polygon_points) >= 2` の場合に `canvas.create_line(...)` で折れ線を描画。
  - 右クリック確定時:
    - 途中線タグを削除してから `canvas.create_polygon(...)` に置き換える。
  - 移動系処理:
    - `on_mouse_drag` 内の再描画時に、確定前なら途中線、確定後なら多角形を再描画。
- 影響想定:
  - `on_mouse_down`
  - `on_mouse_drag`
  - `right_click`
  - `set_mode_polygon` / `clear_selectarea` / `reset_to_startup_state`

---

## 6. 受け入れ条件

- [ ] 多角形モードで2点以上クリックすると、点どうしの途中線が表示される。
- [ ] 途中線は閉じず、最後の点から最初の点への線は右クリック確定前には表示されない。
- [ ] 右クリック確定後は従来どおり閉じた多角形表示になる。
- [ ] 頂点移動・多角形移動時に線表示が破綻しない。
- [ ] 範囲クリア・モード切替・画面リセットで途中線が残留しない。
- [ ] 文字化けが発生していない。
