# モード状態表示ステータスバー 仕様書

> 作成日: 2026-09-18  
> ステータス: Draft  
> 用途: /add-feature への入力

---

## 1. 背景・目的

本アプリには以下の操作モードがあり、現在どのモード中かがユーザーに伝わりにくい。

- ① 標準色見本処理モード（標準色見本処理ボタン）
- ② スケーリングモード（スケーリングボタン）
- ③ 範囲選択モード（四角形/多角形/円形）

メイン画面の最下部に常時表示のステータスバーを追加し、現在状態を一目で判別できるようにする。

## 2. スコープ

### 今回含めるもの
- メイン画面下部への常時表示ステータスバー追加
- 3モードの現在状態表示
- モード切替時の即時更新

### 今回含めないもの
- 各モードの処理ロジック変更
- モード切替ルール自体の変更
- 既存ボタン配置の大幅変更

## 3. 機能要件

### 3.1 配置要件
- [ ] ステータスバーはメイン画面最下部に配置する。
- [ ] メイン画面表示中は常に表示し、右ペインのスクロールに巻き込まれない。
- [ ] ウィンドウリサイズ時も横幅いっぱいに追従する。

### 3.2 表示内容（ユーザー表示文言）
- [ ] ステータスバーは単一テキスト表示とし、表示文言は以下の3種類のみとする。
  - `モード：標準色見本の選択`
  - `モード：スケーリングの設定`
  - `モード：範囲選択`
- [ ] 上記3モードに該当しない状態では、モード表示テキストを表示しない（空表示）。

### 3.2.1 表示優先順位
- [ ] 複数条件が同時に成立し得るため、表示は以下の優先順位で1つに決定する。
  1. 標準色見本処理モード（ON）
  2. スケーリングモード（ON）
  3. 範囲選択モード（四角形/多角形/円形）
- [ ] どれにも該当しない場合は空表示。

### 3.3 更新タイミング
- [ ] 標準色見本処理ボタンのON/OFF切替時に更新する。
- [ ] スケーリングボタンのON/OFF切替時に更新する。
- [ ] 範囲選択ラジオボタン切替（四角形/多角形/円形）時に更新する。
- [ ] `clear_selectarea`、`reset_to_startup_state` など初期化導線でも表示が矛盾しない。

### 3.4 優先表示（補足）
- [ ] ステータスバーは「排他的な単一モード名」を表示する。
- [ ] 同時成立時は 3.2.1 の優先順位に従う。

## 4. 非機能要件

- 可読性: 小さすぎず、既存UIと調和する文字サイズ・配色であること
- 一貫性: ボタン状態（ON色）とステータス表示が矛盾しないこと
- 安定性: 既存処理（画像表示、解析、出力）へ影響を与えないこと

## 5. 実装メモ（案）

- 追加UI:
  - `status_bar_frame`（`root`直下、`side=tk.BOTTOM`, `fill=tk.X`）
  - `status_bar_label`（左寄せ表示）
- 追加関数:
  - `update_mode_status_bar()`  
    - `swatch_toggle_on.get()`
    - `scaling_toggle_on.get()`
    - `mode`（`rect/polygon/circle`）
    を読み、優先順位で以下いずれか1つ、または空文字を設定する
    - `モード：標準色見本の選択`
    - `モード：スケーリングの設定`
    - `モード：範囲選択`
    - `""`（空表示）
- 呼び出し箇所:
  - `toggle_swatch_mode`
  - `toggle_scaling_mode` / `deactivate_scaling_mode`
  - `set_mode_rect` / `set_mode_polygon` / `set_mode_circle`
  - 初期化完了時（アプリ起動時1回）

## 6. 受け入れ条件

- [ ] メイン画面下部に常時ステータスバーが表示される
- [ ] スクロールしてもステータスバーは常時見える
- [ ] 標準色見本処理ON時は `モード：標準色見本の選択` が表示される
- [ ] スケーリングON時は `モード：スケーリングの設定` が表示される（標準色見本処理ON時を除く）
- [ ] 範囲選択中は `モード：範囲選択` が表示される（上位モードがない場合）
- [ ] 上記以外の状態では空表示になる
- [ ] 同時成立時に優先順位どおり1つだけ表示される
- [ ] 既存の解析処理・Excel出力・選択挙動に回帰がない
- [ ] 文字化けが発生しない
