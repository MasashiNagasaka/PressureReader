# 開発ワークフロー遵守ガードレール

1. `src/` 以下のファイルを作成・編集する前には、`docs/ideas/` 配下に 実装計画 あるいは 仕様書 を作成すること。
2. `/add-feature`、`/add-feature-ui`あるいはそれに準ずるカスタムコマンドを実行して、
`.steering`ディレクトリ配下にステアリングファイル（`requirements.md`、`design.md`、`tasklist.md`）を作成してから実装を開始すること。

3. Python依存関係を追加・更新・検証する場合は、`.claude/rules/python-dependency-whitelist.md` を必ず参照し、ホワイトリスト照合を完了してから実施すること。

## Pythonホワイトリスト参照ルール（最優先）
- Python依存関係の追加・更新・検証を伴う場合は、必ず .python_packages_list/ ディレクトリを確認すること。
- **ファイル名を固定決め打ちしてはならない。** .python_packages_list/ 配下の実在ファイルを列挙し、参照対象を決定すること。
- .python_packages_list/ フォルダ、または参照すべきホワイトリストファイルが存在しない場合は、**そのまま処理を進めることを厳禁**とする。
- 上記不足がある場合は処理を停止し、**必ずユーザーに確認を取ってから**再開すること。
- 本節は、ホワイトリスト名の固定例示より優先して適用する。
